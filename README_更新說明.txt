霓光突擊敵人AI：新增games/neonstrike/navigation.js，地圖建好後產生0.5公尺導航格，敵人以A*尋路繞過建築；沒有前進會重新尋路，連續卡住會脫困並換目標。巡邏改為全圖路線點，會循槍聲／爆炸調查、發現玩家時呼叫隊友，久未接觸時分批搜索玩家附近。
霓光突擊地圖：新增districts.js與district-maps.js。港區加入可進入的倉庫、裝卸棚、貨櫃堆場與龍門吊、軍械所與瞭望塔、船員宿舍、油槽區、沙包、護欄、車輛、路燈與地面標線；工廠加入鑄造廠房、模具工坊、冷卻塔、爐渣場、輸送帶、電弧爐與鋼捲倉。區域數港區15、工廠11。
攀爬與移動：港區瞭望塔與儲槽的梯子可攀爬，朝梯子移動往上、遠離往下、空白鍵放手；空中差一點搆到的邊緣會自動攀上。裝卸棚平台兩端改為可直接走上的樓梯，後門改到平台高度並加門外平台與樓梯；上下樓梯時鏡頭平滑跟上，下樓貼著台階走。
穿模與閃爍：地圖建好後自動為看得到、會擋子彈卻沒有碰撞的零件補上碰撞；建築底部飾條在門口斷開；工廠西側管架加上檢修走道與梯子；港區西側鷹架護欄加上碰撞，兩端仍可跳上跳下。背景天際線不再出現在地圖四角內，地圖邊界可走到圍牆邊；儲槽頂等重疊面錯開，不再閃爍雜訊。
介面：敵軍搜索提示、進入區域提示、低血量警示、暫停選單視角靈敏度、結算評等與六項戰績、彈藥偏低提示。小地圖敵人統一為紅點，只有首領為橘色菱形，補給統一為淺色小方塊；視野外的攻擊者以準星外圈箭頭提示。修正受擊箭頭常駐畫面與首領戰區域提示重疊。
穩定與效能：原本0.5秒卡頓即自動暫停，改為2.5秒以上才暫停；部署時預先編譯材質。靜態小物件依材質與區塊合併、極小零件不投影，每幀繪製呼叫（含陰影）港區約少32%～50%、工廠約少23%～50%。
驗證：首頁24組跨尺寸檢查與關鍵互動回歸；格式整理逐一比對JavaScript語法樹；霓光突擊在瀏覽器實測兩張地圖、四種任務、梯子、碰撞與敵人移動。細節及未執行的項目見更新與測試紀錄.md。
版本：網站修訂只保留一章r14。網站與遊戲入口快取標記為20261104-blueworld-r14-source，霓光突擊與頁面版本改為20261113-blueworld-r14-districts；存檔格式與圖片素材不變。原測試紀錄.md改名為更新與測試紀錄.md，霓光突擊assets/cover-art-notes.md改名為assets/封面插畫說明.md。

r13｜2026-10-30 整合更新
版本辨識：20261030-blueworld-r13-touch
本日更新統一記為r13，接續r12，僅記錄最終完成的狀態。

遊戲與推薦：新增NEON STRIKE，含兩張地圖、四種任務、完整模組與音效；新作橫向主卡加四張雙欄卡，760px以下單欄。戰術突襲推薦排第一，點推薦會定位卡片而不開啟遊戲。
直接遊玩：3D模組與八種音效打包為browser.js，本機雙擊與GitHub Pages均可載入，不必啟動本機伺服器。Esc暫停並釋放滑鼠，返回時停止聲音與繪製，重進由玩家繼續。
茜的收藏：三季圖庫33張（9／16／8），話數與立繪分開排序。四張橫幅依序為新年、魔女、聖誕、春櫻和服；統一深藍外框，編號1至4。新增素材只含黑川茜，保留原作標記及來源，不展示SAMPLE商品圖。
肖像切換：日常、雨日及慶典三款直幅，一次只顯示一張，取消側邊縮圖；主題與左右按鈕同步文字、來源及編號。圖文比例、固定展示框與手機單欄一起調整，放大清單獨立循環三張。
小茜互動：只保留襯衫、日常兩款同風格插畫；送星、星光連線、角色問答、四對翻牌記憶、三種心情籤與四款目標色調配，共六種玩法。離開玩法會取消翻牌計時，短句明確標為本館原創，滑桿可用方向鍵。
全站整理：造型資料移至表情觀察之前，導覽與書籤同步；沿用Akane字型和統一平面按鈕。當日紀錄合併，r12及r11重複補修一起整理，每個版本只留一筆，其他舊版維持新到舊。
手機操作：NEON STRIKE新增左搖桿、右滑動視角與可拖曳連射的射擊鍵；瞄準／衝刺可切換，另有跳躍、換彈、技能、手榴彈預覽／投擲／取消及暫停。支援多指、直橫向、手機電腦模式與獨立開啟；取消觸控、旋轉、切背景、暫停或返回時清除操作。手機首次預設流暢畫質並限制渲染倍率；大廳、HUD與觸控按鈕依實際螢幕縮放。修改仍併入r13。
版本與操作收尾：本日更新接續r12統一為r13，說明、版本檔、頁尾、網站腳本及遊戲入口快取一致。肖像主題新增方向鍵、Home／End切換，焦點與選中狀態同步。
