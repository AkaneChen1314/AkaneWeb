Blue World 1.2｜整合更新紀錄

r13｜2026-10-30 整合更新
版本辨識：20261030-blueworld-r13
本日更新統一記為r13，接續r12，僅記錄最終完成的狀態。

遊戲與推薦：新增NEON STRIKE，含兩張地圖、四種任務、完整模組與音效；新作橫向主卡加四張雙欄卡，760px以下單欄。戰術突襲推薦排第一，點推薦會定位卡片而不開啟遊戲。
直接遊玩：3D模組與八種音效打包為browser.js，本機雙擊與GitHub Pages均可載入，不必啟動本機伺服器。Esc暫停並釋放滑鼠，返回時停止聲音與繪製，重進由玩家繼續。
茜的收藏：三季圖庫33張（9／16／8），話數與立繪分開排序。四張橫幅依序為新年、魔女、聖誕、春櫻和服；統一深藍外框，編號1至4。新增素材只含黑川茜，保留原作標記及來源，不展示SAMPLE商品圖。
肖像切換：日常、雨日及慶典三款直幅，一次只顯示一張，取消側邊縮圖；主題與左右按鈕同步文字、來源及編號。圖文比例、固定展示框與手機單欄一起調整，放大清單獨立循環三張。
小茜互動：只保留襯衫、日常兩款同風格插畫；送星、星光連線、角色問答、四對翻牌記憶、三種心情籤與四款目標色調配，共六種玩法。離開玩法會取消翻牌計時，短句明確標為本館原創，滑桿可用方向鍵。
全站整理：造型資料移至表情觀察之前，導覽與書籤同步；沿用Akane字型和統一平面按鈕。當日紀錄合併，r12及r11重複補修一起整理，每個版本只留一筆，其他舊版維持新到舊。
版本與操作收尾：本日更新接續r12統一為r13，說明、版本檔、頁尾、網站腳本及遊戲入口快取一致。肖像主題新增方向鍵、Home／End切換，焦點與選中狀態同步。

r12｜字體、可讀性與UI統一（2026-10-22～23）

- 新增ui-refresh.css作為最後樣式層；中文統一Akane Sans，搭配封裝Japanese／Symbols，純英文標籤保留Blue World Display，同句字重一致。
- 放大來源、標籤與說明，提高文字對比和行距；主要控制至少44px，按鈕統一深藍、12px圓角與平面回饋，移除上浮與側移。
- 入口卡取消被裁切英文裝飾；人物肖像取消左上及直排標籤；動態圖取消編號及多餘英文小標，關閉叉號以CSS置中。
- 三張動態卡的圖片、粗體標題與來源對齊，調整內容間距及手機電腦模式換行；手機頁首分兩排，窄螢幕卡片自然堆疊。
- 三季圖庫簡化為全部、劇照、收藏篩選；當時檢查桌機、390px手機與980px手機電腦模式，沒有水平溢出或瀏覽器錯誤。四款遊戲玩法與存檔未修改。

r11｜STARBREAK整合與手機操作（2026-10-04～05）

- 新增第四款STARBREAK、獨立封面、介紹及推薦，公開顯示1.2，保留來源v1.5玩法及原有存檔格式。四張封面取消流水編號。
- Boss本體／防護罩移出Canvas，戰況視窗暫停且不自動繼續，起始武器保留原生展開操作。
- 手機電腦模式改用全寬戰場及下方加大操作列，武器放下方雙欄；依觸控與實際螢幕判斷，旋轉與字型載入時重新量測，一般手機／鍵盤版不誤套。
- 修正出航／接續的捲動位置；返回會清空輸入、暫停保存，隱藏時停止繪製與時間，重進由玩家繼續。
