四、使用本次更新包
------------------
1. 適用已經有四款遊戲的上一份 r11 網站，先備份儲存庫。
2. 解壓更新包，第一層直接是根目錄檔案與 games/，沒有外層資料夾。
3. 將根目錄 7 個檔案依原檔名覆蓋。
4. 將 games/starbreak/ 的 7 個檔案放到對應位置。
   tests/custom-v15.test.cjs 必須放在 starbreak/tests/ 內。
5. 只覆蓋同名檔案，不要刪掉或用整個 games/ 取代原本資料夾。
   更新包沒有圖片，也沒有前三款遊戲，不能用來獨立發布。
6. 一次提交變更，等待 GitHub Pages 最後一筆部署完成。
7. 原始碼搜尋 20261004-blueworld-r11-touch，可核對這次補修。
8. 若仍看到編號或舊操作列，請重新整理或清除這個網站的快取。

使用 GitHub Desktop 時，把更新包內容複製到本機儲存庫根目錄，
選擇合併資料夾與覆蓋同名檔案，確認變更後提交即可。
使用 GitHub 網頁時，根目錄檔案、starbreak 檔案與 tests 檔案
分開上傳到對應位置；先確認上傳清單的路徑沒有被攤平。
不要直接上傳 ZIP，GitHub Pages 不會替你解壓。

五、使用完整包與首次 r11 的歷史範圍
-----------------------------------
完整包內的 AkaneWeb-main/ 包含全部網站、圖片與四款遊戲。
第一次發布、仍是三款遊戲的舊版，或想完整備份時使用完整包。
把 AkaneWeb-main 資料夾裡的全部內容放到儲存庫根目錄，
保持 index.html、assets/、games/、shared/ 位於同一層。
不需要 npm、編譯或額外安裝程式。

首次 r11 對當時上傳的三款遊戲網站，新增 29 個檔案、修改 8 個
檔案，包含 games/starbreak/ 的 28 個檔案與本清單；沒有刪檔。
那次加入四款遊戲的內容仍完整保留。本次更新包則只比較上一份
已完成的 r11，請不要把兩個比較基準混在一起。
