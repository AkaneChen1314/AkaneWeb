# 黑川茜的藍色收藏館 1.2

本次整理版：20261003-bluehour-r6。網站與三款遊戲版本維持 1.2。

## 解壓後發布到 GitHub Pages

1. 解壓縮 `akane-blue-hour-v1.2-20261003-r6.zip`。
2. 打開裡面的 `akane-blue-hour-v1.2-20261003-r6` 資料夾。
3. 上傳**裡面的內容**到儲存庫根目錄，讓 `index.html` 與 `assets`、`games`、`shared` 資料夾保持同一層。
4. 到儲存庫的 Settings → Pages，選 Deploy from a branch，再選你的分支與 `/ (root)`。
5. 儲存後等待部署完成，再開啟 GitHub Pages 網址。

不用安裝套件、編譯或上傳 `.vscode`。不要把全部內容散開到根目錄：圖片要留在 `assets`，遊戲要留在 `games`。若更新後還看到舊版，在電腦按 Ctrl + F5，並核對原始碼中的 `akane-edition` 是否為 r6。

官方發布說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 這版有哪些更新

- 修正排練室合照說明：畫面中央是茜，左右是佳奈與姬川大輝。
- 六個側邊影片與首頁三張動態卡片各用不同片段，共九段；不再跨區重播同一段裝飾。
- 三張表情觀察室照片保留在觀察室，不再同時出現在圖庫；與人物肖像使用同一幅插畫的第一季立繪也移出圖庫。
- 三季圖庫共 30 張：第一季 8、第二季 16、第三季 6。新增第 14 話茜與阿奎亞的日落劇照；劇照按累計話數排列，兩張第二季立繪另外列。
- 人物介紹下方新增閱讀路線，可跳到 12 個內容／季數位置；往下閱讀會顯示低調書籤。成長脈絡捷徑會自動展開劇情筆記，各季捷徑會先選季數再跳到圖庫。
- 小茜區有四款造型、三種背景光。新增官方和服立牌、音符抱枕示意圖，標示原圖與來源，保留原本 SAMPLE 標記。
- 小互動包括送星星與原創鼓勵短句、無倒數的六顆星連線、五題官方角色資料小問答。星星數量存在目前瀏覽器，沒有帳號或跨裝置同步。

## 全站內容與素材

全站封裝 44 張不同角色圖片及九段無聲影片。圖片以官方角色資料、動畫劇照、官方節慶插畫與授權周邊示意圖為主；入口與資料頁另保留收藏者提供的素材。素材各有自己的展示位置，點圖放大只是檢視同一張，不另算新增圖片。

角色圖片與影片不依賴外部主機載入；只有點來源連結才會前往外站。影片可手動暫停，切換專區、放大圖片、進入遊戲或切離瀏覽器分頁時會暫停。系統偏好減少動態時預設顯示靜態預覽。

三款自製小遊戲與黑川茜無關；三張遊戲封面沿用先前的情境插畫，非遊戲截圖。遊戲封面不顯示版本，遊戲內仍為 1.2。返回按鈕可回到小遊戲專區，同次開啟時可接續。

## 深境冒險圖鑑

圖鑑只供閱讀，不提供指定追獵刷怪。實際遭遇過的怪物才解鎖名字、特性與掉落材料，未發現的項目不顯示詳情。圖鑑與演出設定為獨立按鈕，問號保留玩法說明。

舊存檔會從目前敵人與保留的遭遇紀錄補登；沒有保留紀錄的過去遭遇，需再次遇到才解鎖。舊存檔若正在追獵，會返回原樓層，不發放追獵獎勵。r6 未變更三款遊戲程式與存檔格式。
