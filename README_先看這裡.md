# Blue World 1.2

最終整理版：`20261004-blueworld-r10`。網站與三款遊戲版本都維持 1.2，不需要安裝套件或執行編譯指令。

## 解壓後發布到 GitHub Pages

1. 解壓縮 `blue-world-v1.2-final.zip`。
2. 打開解壓後的 `blue-world-v1.2-final` 資料夾。
3. 把資料夾**裡面的全部內容**放進 `AkaneWeb` 儲存庫根目錄；`index.html` 必須和 `assets`、`games`、`shared` 位於同一層。
4. 一次提交全部變更，等待 GitHub Pages 的最後一筆部署完成。
5. 開啟 `https://akanechen1314.github.io/AkaneWeb/`，在原始碼搜尋 `20261004-blueworld-r10` 即可確認新版已上線。

建議使用 GitHub Desktop 一次提交，因為 GitHub 網頁上傳一次最多只能處理有限數量的檔案。若用網頁分很多次上傳，每一個 `Add files via upload` 都會各自觸發部署；中間那一次可能出現紅叉，但應以**全部檔案上傳完成後的最後一筆部署**為準。不要把 ZIP 本身直接上傳，GitHub Pages 不會自動解壓。

`.vscode` 不需要上傳；本包已附 `.nojekyll`。如果檔案總管看不到它，使用 GitHub Desktop 提交仍會正常保留。

## 全站內容與素材

全站封裝 44 張不同角色圖片與九段無聲循環影片。圖片、影片、字型與三款遊戲都在本機檔案中，不依賴外站載入；只有按下來源連結時才會前往外部網站。

三款自製小遊戲與黑川茜無關。遊戲封面不顯示版本，進入遊戲後仍會看到 1.2；遊戲上方的「返回遊戲館」可回到網站並在同一次開啟期間接續遊玩。

## 深境冒險圖鑑

圖鑑只供閱讀，不提供指定追獵刷怪。實際遭遇過的怪物才會解鎖名稱、特性與掉落素材；未發現的怪物不顯示詳細內容。圖鑑與演出設定各有獨立按鈕，問號只保留玩法說明。

舊存檔會從目前敵人與保留的遭遇紀錄補登。已結算的特殊事件會保存結果卡，重新載入不會重複領獎或扣款。
