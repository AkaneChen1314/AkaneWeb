# 黑川茜的遊戲館 1.2

藍色系黑川茜同人主題首頁，整合三款遊戲。網站與三款遊戲的公開版本均為 **1.2**。

## 馬上遊玩

完整解壓縮後，用 Chrome、Edge、Firefox 或 Safari 開啟最外層的 `index.html`。先查看遊戲介紹，再按「開始遊玩」。遊戲上方的「返回遊戲館」可以返回首頁；再次選同一款遊戲可繼續。

所有圖片、字型與程式都在資料夾裡，不需要安裝、不需要 npm、不需要編譯，也不依賴外部圖片或字型網站。

## 發布到 GitHub Pages

1. 開啟要放網站的 GitHub repository（儲存庫）。
2. 按 **Add file → Upload files**。
3. 把解壓縮後最外層的檔案與資料夾整批拖進去：`index.html` 要在儲存庫根目錄；`assets`、`shared`、`games` 也要完整上傳。不要只上傳 ZIP，也不要多包一層資料夾。
4. 按 **Commit changes**。
5. 第一次發布時，到 **Settings → Pages**，來源選 **Deploy from a branch**；分支通常選 `main`，資料夾選 **/ (root)**，按 **Save**。
6. 等 GitHub 完成發布，開啟 Pages 顯示的網址。已啟用 Pages 的網站，往後通常只需更新檔案並 Commit。

網站使用相對路徑，可以放在 `https://帳號.github.io/儲存庫名稱/`。ZIP 最外層附 `.nojekyll`；Windows 若沒顯示它，也不影響本網站的普通檔案。

## 返回與存檔

- **同一次開著網頁期間**：返回首頁不會重載遊戲。可以換另一款，再回來接續。
- **炒股人生**：返回時暫停自動時間，使用原本的自動存檔。回到遊戲後恢復，但保留你自己設定的「暫停行情」。
- **深境冒險**：保留原本的自動存檔，操作中離開時，以最後完整回合為準。
- **星界牌陣**：沒有跨重新整理的對戰存檔；返回首頁可以接續，但重新整理、關閉網頁或換裝置會重開。
- 自動存檔在同一瀏覽器、同一網站來源保存，沒有雲端同步。換網域、清除資料或禁止儲存可能無法接續。
- 移到原本相同的 GitHub 網站來源時，沿用原存檔鍵與內部格式，不為更新公開版本而清除存檔。
- 直接開 `games/某款遊戲/index.html` 也有返回連結，但這樣跳回首頁會重載；要保留本次卡牌對戰，請從遊戲館進入。

## 想改字或顏色，要開哪個檔案？

| 修改內容                 | 檔案                                              |
| ------------------------ | ------------------------------------------------- |
| 首頁標題、卡片與頁尾文字 | `index.html`                                      |
| 介紹視窗的玩法與提醒     | `main.js` 最上方的 `games` 資料                   |
| 配色、首頁排版、手機版   | `styles.css`；頂端 `:root` 集中定義主要顏色       |
| 主視覺與遊戲插畫封面     | `assets/`                                         |
| 共用返回、休息與中文字型 | `shared/`                                         |
| 深境冒險畫面、戰鬥與樣式 | `games/abyss/index.html`、`game.js`、`style.css`  |
| 卡牌遊戲與戰鬥演出       | `games/arcane/game.js`、`spectacle.js`、CSS 檔案  |
| 炒股遊戲介面             | `games/trader/index.html`、`app.js`、`styles.css` |
| 炒股遊戲資料與計算       | `games/trader/engine.js`                          |

HTML、CSS、JS 都已分行與縮排。建議用 VS Code 打開整個資料夾。`vendor/pako.js` 是炒股存檔使用的第三方函式庫，已保留並整理排版，通常不必修改。

公開版本是 1.2；存檔裡的數字 `version` 是內部格式識別碼，為舊存檔相容保留，請勿手動更改。

黑川茜角色屬於《我推的孩子》相關權利人。本網站為非官方同人主題，主視覺是生成式同人插畫，三款封面是生成式情境插畫，非官方素材；封面用來呈現主題氛圍，並非實際遊戲畫面。字型與第三方程式授權文件保留在各自資料夾。

GitHub 官方發布說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 深境冒險圖鑑修訂

怪物圖鑑現在只供閱讀，已移除指定追獵刷怪。只有實際遭遇過的魔物會解鎖名字、特性與掉落素材；未發現的項目不顯示詳細資料，抵達高樓層也不會自動解鎖全部怪物。圖鑑與演出設定移到遊戲上方的獨立按鈕，問號只保留玩法說明。

舊存檔從目前敵人與保留的遭遇紀錄補登；無紀錄的過去遭遇無法推測，需再次遇到才解鎖。若舊存檔正在追獵，會安全返回原樓層，不發放追獵獎勵，原本持有物品與進度保留。

## 首頁視覺與互動更新

三款遊戲改用同一套藍色插畫封面：水晶深境、星界魔法與夜色金融城市。介紹視窗也使用新封面。

- 背景加入星空、光暈與兩側軌道圖紋；電腦滑鼠移動會帶出光影與附近星光連線。
- 遊戲卡片有跟隨滑鼠的柔和光暈，滑過時封面微微放大。
- 「今天的心情是？」會標示適合的遊戲；「交給命運」隨機打開一款的介紹，確認玩法後才開始。
- 增加茜的休息室、三段旅程介紹與封面標語。
- 手機以靜態星空呈現；啟用減少動態效果時關閉動畫。進入遊戲或切到背景分頁時，星空動畫會暫停。

新增的 `ambience.css` 控制背景、推薦列與休息室排版；`ambience.js` 控制星光與滑鼠效果。這兩個檔案都已分行、縮排並加上中文註解。公開版本維持 1.2。
