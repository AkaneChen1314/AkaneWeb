# 黑川茜的藍色收藏館 1.2

藍色系黑川茜粉絲收藏館，分為首頁、黑川茜專區與小遊戲專區。網站與三款遊戲的公開版本均為 **1.2**。

## 馬上遊玩

完整解壓縮後，用 Chrome、Edge、Firefox 或 Safari 開啟最外層的 `index.html`。先進入「小遊戲專區」，查看遊戲介紹，再按「開始遊玩」。遊戲上方的「返回遊戲館」可以返回首頁；再次選同一款遊戲可繼續。

所有圖片、無聲影片、字型與程式都在資料夾裡，不需要安裝、不需要 npm、不需要編譯，也不依賴外部圖片或字型網站。

## 發布到 GitHub Pages

1. 開啟要放網站的 GitHub repository（儲存庫）。
2. 按 **Add file → Upload files**。
3. 把解壓縮後最外層的檔案與資料夾整批拖進去：`index.html` 要在儲存庫根目錄；`assets`、`shared`、`games` 也要完整上傳。不要只上傳 ZIP，也不要多包一層資料夾。
4. 按 **Commit changes**。
5. 第一次發布時，到 **Settings → Pages**，來源選 **Deploy from a branch**；分支通常選 `main`，資料夾選 **/ (root)**，按 **Save**。
6. 等 GitHub 完成發布，開啟 Pages 顯示的網址。已啟用 Pages 的網站，往後通常只需更新檔案並 Commit。

網站使用相對路徑，可以放在 `https://帳號.github.io/儲存庫名稱/`。ZIP 最外層附 `.nojekyll`；Windows 若沒顯示它，也不影響本網站的普通檔案。

## 返回與存檔

- **同一次開著網頁期間**：返回首頁不會重載遊戲。可以換另一款，再回來接續。
- **炒股人生**：返回時暫停自動時間，使用原本的自動存檔。回到遊戲後恢復，但保留你自己設定的「暫停行情」。
- **深境冒險**：保留原本的自動存檔，操作中離開時，以最後完整回合為準。
- **星界牌陣**：沒有跨重新整理的對戰存檔；返回首頁可以接續，但重新整理、關閉網頁或換裝置會重開。
- 自動存檔在同一瀏覽器、同一網站來源保存，沒有雲端同步。換網域、清除資料或禁止儲存可能無法接續。
- 移到原本相同的 GitHub 網站來源時，沿用原存檔鍵與內部格式，不為更新公開版本而清除存檔。
- 直接開 `games/某款遊戲/index.html` 也有返回連結，但這樣跳回首頁會重載；要保留本次卡牌對戰，請從遊戲館進入。

公開版本是 1.2；存檔裡的數字 `version` 是內部格式識別碼，為舊存檔相容保留，請勿手動更改。

黑川茜角色及官方圖片屬於原權利人。角色區與首頁共使用 34 張不同的角色圖片；其中 31 張取自動畫官網，伸手入口另附網路來源，夕光入口與造型資料頁由收藏者提供；遊戲區三張封面是生成式情境插畫，非實際遊戲截圖。三季圖庫與角色資料都有來源連結，素材明細在 `assets/akane/sources.json` 與 `圖片與資料來源.md`。本站為非官方粉絲主題，下載圖片不代表取得公開使用授權。

## 深境冒險圖鑑修訂

怪物圖鑑現在只供閱讀，已移除指定追獵刷怪。只有實際遭遇過的魔物會解鎖名字、特性與掉落素材；未發現的項目不顯示詳細資料，抵達高樓層也不會自動解鎖全部怪物。圖鑑與演出設定移到遊戲上方的獨立按鈕，問號只保留玩法說明。

舊存檔從目前敵人與保留的遭遇紀錄補登；無紀錄的過去遭遇無法推測，需再次遇到才解鎖。若舊存檔正在追獵，會安全返回原樓層，不發放追獵獎勵，原本持有物品與進度保留。

## 收藏館與互動

- **首頁**：漸層藍官方第三季立繪、兩張不同的柔邊伸手引導圖片、角色／遊戲專區入口與三季捷徑。
- **黑川茜專區**：官方人物肖像、基本資料、可放大的造型／表情資料室、觀賞筆記、可展開的劇情脈絡、29 張分季立繪／劇照，以及官方來源。
- **小遊戲專區**：保留三款遊戲、心情推薦、隨機挑選、玩法介紹與返回／接續功能。
- **圖庫**：先切換第 1、2、3 季，各季獨立顯示；劇照按累計話數排列，也可選指定一話。立繪另列，可篩選劇照、立繪或本季收藏。點圖放大，以左右鍵切換，Esc 關閉；手機也有左右按鈕。
- **收藏**：在同一網址與瀏覽器保存，沒有登入或跨裝置同步；若瀏覽器不允許儲存，仍可在本次開啟期間使用。
- **舞台光效**：導覽右側按鈕可開關。桌面有星空、光束與滑鼠光暈；手機與減少動態模式使用輕量效果。開啟遊戲與切到背景分頁時，Canvas 動畫暫停。

版本維持 1.2，所有圖片與四段無聲循環影片均隨 ZIP 打包。打開網站不需要連到外部圖片主機；只有點來源連結時才會前往外站。

## 三季圖庫的順序

第一季收錄 7 張、第二季 15 張（13 張劇照＋2 張立繪）、第三季 7 張。劇照按官網累計話數與同話原頁圖片順序排列；回憶畫面也放在播出該畫面的那一話。選單只列有收錄圖片的話數，不表示每一話都有人物圖片。

第二季「本季第 1 話」對應總第 12 話；第三季「本季第 1 話」對應總第 25 話。角色立繪沒有指定話數，所以另列在本季劇照之後。收藏可跨季保存，但篩選只顯示目前這一季，放大左右切換也留在目前篩選範圍內。

改圖庫內容請編輯 `gallery-data.js`；改分季互動請看 `archive.js`；改本次漸層藍、角色入口與分季 UI 請看 `seasons.css`。

## 柔邊圖片、資料室與動態收藏

- 首頁上方介紹收藏館，專區入口按鈕留在下方卡片底部。遊戲入口使用收藏者提供的夕光長髮圖片，已校正原圖方向；柔邊與色彩由 CSS 處理，不改畫人物。
- 造型資料室完整收錄 `50.webp`，可切換表情／造型／色彩筆記，點圖放大，再按「看原始尺寸」查看細節。介紹是圖片觀賞筆記，不是未經核實的官方逐字翻譯。
- 首頁放映區有點頭、微笑、戴墨鏡三段不同的動態；電腦側邊另有一段低透明度背景片段。四段都為靜音、循環播放，MP4 與 WebM 兩種格式已封裝。
- 影片進入可見區域時自動播放，持續循環；切換專區、進遊戲、打開放大視窗或把分頁放到背景時暫停。手機不載入側邊背景影片，首頁的三張動態卡片仍可播放。
- 「暫停動態／播放動態」可手動切換，並在同一瀏覽器記住設定。減少動態偏好預設使用靜態預覽，也可以自行按播放。瀏覽器阻擋自動播放時，可以點片段內的播放按鈕。
- 原本三季圖庫仍只有官方劇照與立繪，依話數排列；資料頁與首頁動態獨立陳列，不把來源未核實的季數／話數硬塞進圖庫。
