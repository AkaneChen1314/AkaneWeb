## r12 字體、可讀性與 UI 統一

- 三張動態圖片左上編號標籤統一下移，避免太靠近圖片圓角；人物肖像移除 `OFFICIAL / PROFILE` 與直排 `AKANE` 裝飾，只保留乾淨圖片。
- 全站主介面改為使用專案內建的 `Akane Sans`／`Akane Japanese`／`Akane Symbols`，不再由瀏覽器的預設字體決定呈現。
- 中文標題、導覽、按鈕與內文完整使用 `Akane Sans`，避免同一句因字形回退而忽粗忽細；`Blue World Display` 只保留給純英文標籤。
- 句子內的數字與強調標籤沿用整句字重，不再局部使用粗體；常用按鈕字重也統一為 600。
- 移除首頁兩張專區入口圖片右上方會被裁切的英文裝飾字，重新平衡文字欄寬、人物圖片、卡片留白與按鈕位置。
- 放大原本只有 6–11px 的英文標籤、來源、圖庫資訊、收藏筆記與手機說明；內文行距與對比同步提高。
- 主要按鈕預設統一為深藍漸層，只有滑鼠移入或鍵盤聚焦時才適度提亮；次要按鈕與切換器也使用一致的深藍平面樣式。
- 提高說明、卡片摘要與輔助文字的藍灰色亮度，讓深色背景上的文字更清楚，同時保留標題與內文的層級。
- 移除按鈕與卡片 hover 時的上浮／側移，避免介面同時出現立體、透明、膠囊與位移等過多視覺語言。
- 首頁三張動態卡恢復同列等高，來源連結與底邊對齊；多出的空間集中在內容與來源之間，畫面一致但不會把文字硬拉開。
- 遊戲卡與特別收藏卡的內容收尾對齊，頁首光效按鈕保留穩定寬度，區段標題、換行與鍵盤焦點也做一致化整理。
- 760px 以下的頁首改成清楚的兩排配置，三個專區導覽不會再被品牌或光效按鈕擠出畫面。
- 主要卡片外圓角統一為 20px，控制項為 12px，保留原本藍紫星光、圖片、影片與三種光色。
- 新增 `ui-refresh.css` 作為最後一層樣式，方便日後集中調整，不必在多個舊 CSS 檔中重複覆寫。
- 已檢查 1264px 桌機與 390px 手機版的首頁、黑川茜專區及小遊戲專區；沒有水平溢出或瀏覽器錯誤。

## 解壓後發布到 GitHub Pages

1. 解壓縮本次「完整網站包」。
2. 打開解壓後的 `AkaneWeb-main` 資料夾。
3. 把資料夾**裡面的全部內容**放進 `AkaneWeb` 儲存庫根目錄；`index.html` 必須和 `assets`、`games`、`shared` 位於同一層。
4. 一次提交全部變更，等待 GitHub Pages 的最後一筆部署完成。
5. 開啟 `https://akanechen1314.github.io/AkaneWeb/`，在原始碼搜尋 `20261030-blueworld-r13-touch` 即可確認新版已上線。

建議使用 GitHub Desktop 一次提交，因為 GitHub 網頁上傳一次最多只能處理有限數量的檔案。若用網頁分很多次上傳，每一個 `Add files via upload` 都會各自觸發部署；中間那一次可能出現紅叉，但應以**全部檔案上傳完成後的最後一筆部署**為準。不要把 ZIP 本身直接上傳，GitHub Pages 不會自動解壓。

編輯器設定不影響網站發布。請保留所有遊戲、素材與共用檔案的相對路徑。

## 全站內容與素材

全站封裝55張角色圖片（含目前未展示的留存原檔）與九段無聲循環影片。圖片、影片、字型與五款遊戲都在本機檔案中，不依賴外站載入；只有按下來源連結時才會前往外部網站。

五款自製小遊戲與黑川茜無關。遊戲保留各自的版本；遊戲上方的「返回遊戲館」可回到網站並在同一次開啟期間接續遊玩。NEON STRIKE在電腦可按Esc暫停；手機使用畫面上的暫停鍵，選單也提供返回遊戲館。

## 深境冒險圖鑑

圖鑑只供閱讀，不提供指定追獵刷怪。實際遭遇過的怪物才會解鎖名稱、特性與掉落素材；未發現的怪物不顯示詳細內容。圖鑑與演出設定各有獨立按鈕，問號只保留玩法說明。

舊存檔會從目前敵人與保留的遭遇紀錄補登。已結算的特殊事件會保存結果卡，重新載入不會重複領獎或扣款。
