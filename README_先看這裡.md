# Blue World 1.2

本次整理版：20261004-blueworld-r9。網站與三款遊戲版本維持 1.2。

## 解壓後發布到 GitHub Pages

1. 解壓縮 `blue-world-v1.2-r9.zip`。
2. 打開裡面的 `blue-world-v1.2-r9` 資料夾。
3. 上傳**裡面的內容**到儲存庫根目錄，讓 `index.html` 與 `assets`、`games`、`shared` 資料夾保持同一層。
4. 到儲存庫的 Settings → Pages，選 Deploy from a branch，再選你的分支與 `/ (root)`。
5. 儲存後等待部署完成，再開啟 GitHub Pages 網址。

不用安裝套件、編譯或上傳 `.vscode`。不要把全部內容散開到根目錄：圖片要留在 `assets`，遊戲要留在 `games`。若更新後還看到舊版，在電腦按 Ctrl + F5，並核對原始碼中的 `akane-edition` 是否為 20261004-blueworld-r9。

官方發布說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## r9 位置微調

首頁三張筆記卡片改成在電腦封面的中央，靠在黑川茜旁邊。手機與較窄平板保留三欄卡片正常排列，不套用桌面的位移。

已上傳 r8 時，只需用 `blue-world-layout-r9.zip` 覆蓋根目錄的 `index.html` 和 `world.css`；遊戲與圖片不用重新上傳。

## 這版有哪些更新

- 網站名稱、頁籤、導覽、頁尾與分享標題全面改為 Blue World，遊戲版本維持 1.2。
- 全新 Blue World 大字主視覺、藍紫光環與柔光海平線；優化人物專區、遊戲卡片、導覽與手機版。
- 首頁有深海藍／暮光紫／櫻光藍三種光色，會記住你在此瀏覽器的選擇。
- 分享圖片改成 1200 × 630 的專用 JPG，茜的臉與主標題置中；新增 Open Graph 與 Twitter 分享欄位。
- 百億炒股人生：三種借款都在最初表單檢查有效金額、最低金額與目前上限，超額會留在原頁顯示提示，不先跳到簽約。
- 深境冒險：上帝模式眼睛裝飾不再攔截 X，所有關閉鈕加大至 44 × 44。
- 特殊事件新增持續顯示的結果卡，列出實際金幣、HP、職業資源、素材、藥水、永久攻擊與異常解除。按繼續或結果卡 X 才離開；結果會存檔，不會重複結算。
- 保留 r7 的手機縮放保護與蒼穹決戰排版／特效定位修正，保留分季圖片、九段不同動畫、閱讀路線、小問答、星星連線與四款 Q 版。

## 更新現有網站

若已有 r6／r7，用 `blue-world-update-r8.zip` 即可。裡面只有更新檔，維持資料夾路徑，在 GitHub 儲存庫根目錄上傳並覆蓋同名檔案即可。不要先刪掉舊資料夾。

必須上傳更新包的 `index.html`、`world.css`、`world.js`、`assets`、`games`、`shared`；說明文件可自行決定是否上傳。`assets` 只有一張新分享圖，不需要重新拖全部舊圖片。

## 分享預覽

`index.html` 的 `og:url` 和三處分享圖片網址已依截圖設定為 `https://akanechen1314.github.io/`。如果實際網站在 `/某個儲存庫/` 子路徑，請在這些完整網址中加上同一個子路徑；圖片檔相對路徑不用改。分享圖片的排版原稿放在 `share-card-source.html`，可直接閱讀與修改。

社群／通訊軟體可能保留先前連結的舊預覽。部署完成後可以先分享 `https://akanechen1314.github.io/?v=blueworld-r8` 測試；已送出的舊訊息縮圖不一定會更新。不要只依舊訊息判斷是否部署成功。

## 全站內容與素材

全站封裝 44 張不同角色圖片及九段無聲影片。圖片以官方角色資料、動畫劇照、官方節慶插畫與授權周邊示意圖為主；入口與資料頁另保留收藏者提供的素材。素材各有自己的展示位置，點圖放大只是檢視同一張，不另算新增圖片。

角色圖片與影片不依賴外部主機載入；只有點來源連結才會前往外站。影片可手動暫停，切換專區、放大圖片、進入遊戲或切離瀏覽器分頁時會暫停。系統偏好減少動態時預設顯示靜態預覽。

三款自製小遊戲與黑川茜無關；三張遊戲封面沿用先前的情境插畫，非遊戲截圖。遊戲封面不顯示版本，遊戲內仍為 1.2。返回按鈕可回到小遊戲專區，同次開啟時可接續。

## 深境冒險圖鑑

圖鑑只供閱讀，不提供指定追獵刷怪。實際遭遇過的怪物才解鎖名字、特性與掉落材料，未發現的項目不顯示詳情。圖鑑與演出設定為獨立按鈕，問號保留玩法說明。

舊存檔會從目前敵人與保留的遭遇紀錄補登；沒有保留紀錄的過去遭遇，需再次遇到才解鎖。舊存檔若正在追獵，會返回原樓層，不發放追獵獎勵。r8 保留舊存檔識別；已結算的事件會額外保存結果卡，重新載入不會重複領獎或扣款。
