# Blue World 1.2

目前修訂：`20261004-blueworld-r11`。網站與四款遊戲的公開顯示版本都是 1.2，不需要安裝套件或執行編譯指令。此次接續原本 r10 / Final，沒有更改為 2.0。

## 解壓後發布到 GitHub Pages

1. 解壓縮本次「完整網站包」。
2. 打開解壓後的 `AkaneWeb-main` 資料夾。
3. 把資料夾**裡面的全部內容**放進 `AkaneWeb` 儲存庫根目錄；`index.html` 必須和 `assets`、`games`、`shared` 位於同一層。
4. 一次提交全部變更，等待 GitHub Pages 的最後一筆部署完成。
5. 開啟 `https://akanechen1314.github.io/AkaneWeb/`，在原始碼搜尋 `20261004-blueworld-r11` 即可確認新版已上線。

建議使用 GitHub Desktop 一次提交，因為 GitHub 網頁上傳一次最多只能處理有限數量的檔案。若用網頁分很多次上傳，每一個 `Add files via upload` 都會各自觸發部署；中間那一次可能出現紅叉，但應以**全部檔案上傳完成後的最後一筆部署**為準。不要把 ZIP 本身直接上傳，GitHub Pages 不會自動解壓。

編輯器設定不影響網站發布。請保留所有遊戲、素材與共用檔案的相對路徑。

## 只更新現有 GitHub 儲存庫

解壓「新增／修改更新包」，把裡面的檔案依相同路徑放進原儲存庫，確認覆蓋修改的檔案後一次提交即可。更新包沒有外層 `AkaneWeb-main` 資料夾，第一層直接是首頁檔案與 `games`；不要再加一層資料夾。無需刪除舊檔，也不必重傳沒有修改的角色圖片、影片或三款原遊戲。

精確清單在 `README_新增與修改檔案.txt`。更新記錄仍在 `README_更新說明.txt` 與 `測試紀錄.md`。

## r11 第四款遊戲與介面修正

- 新增「星夜突圍：STARBREAK」，保留來源 v1.5 的全部星艦、武器、模式、Boss、商城與備份功能；公開顯示版本依本館統一為 1.2。
- 四張遊戲卡在電腦／平板排成 2 × 2，680px 以下單欄；新封面使用 Starbreak 自己的星海插畫，不與其他遊戲共用封面。
- 新增介紹、三步玩法、適合玩家與心情推薦；先閱讀介紹再開始，仍有遊戲與黑川茜無關的附註。
- Boss 狀態列在畫布外保留小區域，本體／防護罩並列；「戰況 ⓘ」可以暫停查看完整資訊，不會在戰場中央覆蓋攻擊。
- 起始武器設定有箭頭及「點此展開／收合」，保留原生鍵盤與觸控展開。
- 返回時暫停並保存；重新進入按「繼續航行」。開始／接續會回到戰場頂端，避免沿用設定頁的捲動位置。
- 新遊戲沿用原本存檔鍵與備份格式；但不同網域、瀏覽器或裝置的存檔不會自動轉移，請先在舊版匯出 JSON，再在新版「設定與備份」匯入。

## 全站內容與素材

全站封裝 44 張不同角色圖片與九段無聲循環影片。圖片、影片、字型與四款遊戲都在本機檔案中，不依賴外站載入；只有按下來源連結時才會前往外部網站。

四款自製小遊戲與黑川茜無關。遊戲封面不顯示版本，進入遊戲後會看到 1.2；遊戲上方的「返回遊戲館」可回到網站並在同一次開啟期間接續遊玩。

## 深境冒險圖鑑

圖鑑只供閱讀，不提供指定追獵刷怪。實際遭遇過的怪物才會解鎖名稱、特性與掉落素材；未發現的怪物不顯示詳細內容。圖鑑與演出設定各有獨立按鈕，問號只保留玩法說明。

舊存檔會從目前敵人與保留的遭遇紀錄補登。已結算的特殊事件會保存結果卡，重新載入不會重複領獎或扣款。
