## r14｜午夜擂台與霓境蛇行（2026-11-13）

2026-11-13，r14。使用 Codex 內建 image_gen 工具分別生成兩張封面；未使用 CLI 或外部付費 API 金鑰。插畫取材自兩款原創遊戲的角色與場景，用於遊戲館情境封面，並非遊戲實際畫質。

- `cover-midnight-art.webp`：雷隼與霜弦在雨夜工業天台對決，分別呈現金色電光與冰藍能力。
- `cover-serpent-art.webp`：翡翠蛇靈於螢光森境收集食物、進化晶體，周圍有蟲群與治癒泉。

- 原 `cover-midnight.png`、`cover-serpent.png` 是前一版遊戲實景截圖，保留作紀錄，不再用於入口卡片。
