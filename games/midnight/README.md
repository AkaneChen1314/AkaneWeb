# 午夜擂台｜網站整合版

來源為使用者提供的 E:\FightGame。原資料夾保留不變，只發布 index.html、styles.css、src/ 與 assets/。

支援單人、同裝置雙人、練習、街機；鍵盤、觸控與相容手把。詳細按鍵以遊戲內「操作說明」為準。

src/app.js 加入 akane-portal-state 父頁訊息處理：返回專區會清除輸入、暫停戰鬥與音訊；重新進入後手動繼續。外觀沿用遊戲原色，字體使用網站 shared/fonts.css。

## r15（2026-11-23）的調整

原本的三張角色圖、場景圖與招式名稱都保留，重新調整距離、手感、動作、畫面與電腦。

- 距離：打擊算到對手的身體邊緣，差一點點時出招會自動跟步，再遠一點會先衝到對手面前才出手，停在拳腳剛好碰到的位置。站著出手最遠：輕攻 248～294（衝步 398～444）、重攻 316～378（衝步 486～552），依鬥士的手腳長短不同（原本輕攻 137、重攻 179）。單下傷害跟著調低。
- 判定：拳腳伸出去之後會維持一小段時間（0.06～0.2 秒），不再只看一瞬間；貼牆時攻擊方會被震退，浮空連擊有上限，被打落地後有短暫無敵。
- 操作：輕攻三段連擊、蹲踢、按住後退自動防禦、閃避與衝刺中可以出招、指令提早按也接得上。按鍵改成兩排（J K L／U I O），防禦改為 F；單人也能用方向鍵加 Z X C V B。
- 動作：`src/rig.js` 用 WebGL2 把原圖切成會彎曲的關節，`src/animation.js` 讓每個招式有起手、打擊、收招；站立、出拳、蹲下三張圖交換時，身體位置會接續，不會跳一下。不支援 WebGL2 時自動改用整張圖。
- 特效：`src/fx.js` 是每位鬥士自己的招式與大招演出（雷、冰、火、影），加上泛光、集中線與畫面壓暗；跟不上時自動先降解析度、再關掉泛光。
- 場景：`src/stage.js` 讓路燈、招牌、霧、電車、閃電與積水動起來，燈光會照在角色身上。
- 畫面：靠近時鏡頭拉近、刀光與拳風沿著真正的手腳軌跡、命中火花打在拳腳的位置、下方能量與技能欄重做。
- 電腦：會抓破綻反擊、連續防禦、截擊猛攻的對手，三個難度重新調整。
- 移除 `assets/walk.png`（1.5 MB）與 `src/walk-frames.js`，走路改由關節動作產生。
