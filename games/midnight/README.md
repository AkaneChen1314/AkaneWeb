# 午夜擂台｜網站整合版

來源為使用者提供的 E:\FightGame。原資料夾保留不變，只發布 index.html、styles.css、src/ 與 assets/。

支援單人、同裝置雙人、練習、街機；鍵盤、觸控與相容手把。詳細按鍵以遊戲內「操作說明」為準。

src/app.js 加入 akane-portal-state 父頁訊息處理：返回專區會清除輸入、暫停戰鬥與音訊；重新進入後手動繼續。外觀沿用遊戲原色，字體使用網站 shared/fonts.css。

## r15（2026-11-21）的調整

- `src/ai.js`：電腦對手。看到對手出招後隔一段反應時間才防禦或反擊，會懲罰揮空、對空、接連段、用投技與下段破防，並記住對手的習慣。難度參數在 `src/roster.js` 的 `DIFFICULTY`。
- 選角畫面新增「電腦對打」：兩邊都交給電腦，可以用來觀戰或看招式。
- 動作：開場跑進場、落地屈膝、受擊縮身與翻轉、勝利與落敗姿勢、待機踮步。
- 畫面：高解析度螢幕的電腦以 1.5 倍繪製（跟不上會自動調回 1 倍）、地板倒影、影子跟著動作變化。
- 介面：受擊時頭像與血條的回饋、結算戰績表、觸控十字鍵（可滑動）、手機橫放時的全螢幕版面。
- 招式的傷害、判定與硬直沒有修改。
