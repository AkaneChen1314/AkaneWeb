星夜突圍 · STARBREAK v1.2（Blue World 整合版 r11）
=========================

本包以原 Starbreak v1.5 為基礎，公開顯示依 Blue World 統一為 1.2，
不是刪掉 v1.5 功能。存檔格式及原本的存檔鍵維持不變。

整合修正：Boss 血量／防護罩改為戰場外精簡列，「戰況 ⓘ」可暫停看完整資訊。
起始武器設定有「點此展開／收合」與箭頭；出航／接續會回到戰場頂端。
返回遊戲館會暫停並保存，再進入請按「繼續航行」。
若原遊戲在另一個網域／瀏覽器，請先匯出 JSON，再在此版匯入。

目前玩法：Boss 依接戰等級與實際裝備成長，總耐久包括階段／限次護盾恢復。
新增四種 Boss 能量演出、破盾／狂暴震波、受控震動與效果設定。
模式各有實際規則；完整說明請讀「操作說明.md」，修改程式請讀「程式導覽.md」。

開啟：由 Blue World 小遊戲專區進入；也可直接開啟本資料夾 index.html。
移動檔案時請保留本遊戲與 ../../shared、../../assets 的相對位置。
離線包包含全部程式與圖片，不需要安裝套件。
手機建議使用線上版；部分檔案預覽器無法執行本機網頁 JavaScript。

操作
電腦：WASD / 方向鍵移動，Space 衝刺，Q 過載，P 或 Esc 暫停。
獎勵：點擊卡片，或按 1、2、3。
手機：左手拖曳移動，右下方大按鈕衝刺／過載，可同時操作。
也支援在戰場空白處拖曳；第二根手指不會搶走移動搖桿。
星艦自動瞄準與開火；切到背景會暫停。

出航畫面
先選星艦與四個方案，再選 1–80 波、六檔難度與航行模式。
五類細項預設收合，每次展開一類：過關、小怪、Boss 登場、Boss 戰鬥、特殊航線。
設定會自動保存在此瀏覽器。方案保留目前星艦、起始武器和難度。
起始武器可選六種，畫面顯示包含研究／模組的生命、速度、減傷、暴擊。
電弧／導彈較少起始生命，軌道刃／新星／冰晶偏耐久或控制；局內取得武器不扣生命。
輕鬆出航：8 波、18 隻起、稀疏敵潮、35 秒 Boss 倒數。
經典遠征：16 波、24 隻起、適中敵潮、45 秒倒數。
星海長征：32 波、30 隻起、密集敵潮、高頻精英、60 秒倒數。
巨獸試煉：8 波、固定 14 隻目標、適中敵潮、高頻精英，每波 30 秒後 Boss 登場。
預設強化耐久、快速出招、密集彈幕、堡壘護盾、三階段與階段恢復；方案本身就是挑戰。
舊自訂設定會保留，要使用新版方案請重新點「巨獸試煉」再開新局。
快捷方案不會改變目前選擇的整體難度。

過關規則
每波小怪擊破目標取代舊版的時間門檻，右上角只顯示「擊破 X / Y」。
起始目標可選 10–160 隻，固定或逐波 +3（最多比起始值多 60）。
沒有 Boss 的波達成目標即過關；Boss 波需同時達成目標與擊敗 Boss。
先達成目標仍要等 Boss 倒數，等待登場時增援減緩，接戰後恢復高壓增援；先擊敗 Boss 仍須完成目標。
Boss 不計入小怪擊破數，自爆機自行引爆也不計入。
分裂幼體、召喚護衛與精英被玩家擊破時均計入。
額外任務是可選的晶礦獎勵，與主要過關目標分開。

Boss
登場倒數可選 15–180 秒，預設 45 秒，倒數到零才生成。
只累計該波實際戰鬥時間；暫停、升級、事件與商城不計時。
出現規則：每 1–12 波、最後一波、每波、完全關閉，可追加最終 Boss。
種類：輪流、隨機或固定四種之一；無盡模式沒有最後一波。
耐久：常規、強化（總耐久 +35%）、霸主（總耐久 +70%）；後兩檔接觸傷害也提高。
二階段可獨立開關，生命低於 50% 進入狂暴。關閉時只有單階段。
可另外開啟終焉階段，生命低於 30% 進入第三階段；需要先開二階段。
頻率：舒緩、標準、快速、連攻，控制兩次招式間隔。
密度：稀疏、標準、密集、極密，控制彈數、禁區與召喚數。
頻率、密度與耐久設定互相獨立。
裂隙吞噬者：裂隙衝鋒、噬星彈環、虛空吞噬。
鋼鐵暴君：熔核齊射、天火轟炸、衛隊與鎖定炮。
星雲女皇：蜂群降臨、結晶針雨、女皇領域。
永夜核心：雙旋星環、末日連鎖、奇點斬擊。
發光核心為命中與碰撞區，翼刃／裝甲為視覺呈現。紅圈、紅線會先預警再攻擊。

新增：Boss 本體和防護罩分開顯示，護盾未破時本體完全免傷，最後一擊不溢出。
護盾可關閉、依難度、輕型 25%、重型 70%、堡壘 115% 本體最大生命。
恢復：不恢復、換階段恢復、階段＋24 秒限次充能（每階段最多 2 次）。
四個 Boss 各五套主招式；高難度同時疊加彈環、螺旋、轟炸和光束，還有護衛。
總耐久、護盾、裝甲、連攻層數、頻率、彈量與接戰增援隨難度提升，自訂頻率／密度再乘。
Boss 在出場時記錄玩家等級與火力，不再直接使用波數疊出數千初始生命。
當前 Boss 數值固定，戰鬥中升級會更快擊破；下一隻才重算。
低等級且火力未成形時少一重連攻；強構築仍會遇到更快、更密的火網。
Boss 有控制／震退抗性；護盾恢復也從同一總耐久預算分配。
休閒單招，標準狂暴雙招；困難第一階段雙招，噩夢曲線連攻，深淵／災厄三至四重連攻。

小怪
數量四檔：稀疏、適中、密集、海量，增援頻率與同場上限都不同。
編隊五種：綜合、高速追擊、遠程火網、重裝軍團、分裂蜂群。
11 種小怪逐波解鎖，專門編隊在第 2 波提前加入對應敵人。
偵察機、疾行機、重裝機、狙擊機、衝鋒機、分裂體、幼體保留。
新增盾衛（減傷 30%）、修復機（每 5 秒修復最多 3 名附近小怪，不能修復 Boss）、
自爆機（1.25 秒預警後爆炸）、散射炮艇（黃線蓄力後發射三方向彈幕）。
自爆機鎖定紅圈後，擊破它也不會取消紅圈爆炸。
精英出現率：關閉、標準、高頻；第 3 波起可遇見裝甲、迅捷、爆裂、再生精英。
第 6 波起部分精英會成為冠軍，有雙重外圈、更高生命與接觸傷害，晶礦掉落更多。

武器、商城與成長
3 種星艦、6 種武器，各 5 級與一種進化；9 種能力、12 件遺物、3 種星域。
武器 Lv.5 ＋指定能力 Lv.2 後，可在升級或商城獲得進化：
脈衝連射 ＋ 超頻迴路 → 雙子湮滅炮
軌道刃 ＋ 偏轉護盾 → 星環絞碎者
連鎖電弧 ＋ 弱點解析 → 雷霆網路
震盪新星 ＋ 裝甲擴建 → 零點超新星
追獵導彈 ＋ 反應爐增壓 → 蜂巢天火
冰晶散射 ＋ 磁力打撈 → 永夜冰河
每波有強化與補給，每 4 波可選遺物與星域，部分波次有事件。
戰場補給箱、四秒連鎖、戰術波型與特殊航線均保留。
波間商城使用本局晶礦買武器、能力、進化、遺物、護盾與重抽券。
可以更新商品，或花 25 晶礦修復 40% 生命，購買狀態會存檔。
結算剩餘晶礦依難度與 Boss 規則倍率帶回基地，通關獎勵按總波數比例計算。
基地有 6 項永久研究、5 個模組、10 項成就；一次出航裝備一個模組。
研究／模組變更只從下次出航生效。
每日種子依台灣日期固定，沒有線上排行榜。

存檔相容
沿用舊版儲存位置，永久研究、成就、晶礦、商城、武器、生命均保留。
v1.2 完整保存該波擊破進度、Boss 倒數、階段與自訂規則。
v1.0／v1.1 沒有該波擊破數，因此舊遠征匯入後該波目標從 0 開始；
已有 Boss 與已累計戰鬥時間會保留，其他裝備／研究不重置。
舊每波秒數不再控制過關，缺少的新設定使用新版預設值。護盾剩餘量、充能次數及連發進度都會保存。
舊局 Boss 首次讀檔換成新版接戰配置，保留本體／護盾各自剩餘比例。
每 10 秒自動保存；選擇獎勵、暫停、保存離開後立即保存。
新出航會先提示結算原有遠征。死亡／撤退／通關只結算一次。
線上、本機、不同瀏覽器的進度獨立，請使用「設定與備份」匯出／匯入。
換本機資料夾或清除瀏覽器資料前也請先匯出 JSON 備份。

畫面與測試
手機有拇指操作區、大技能按鈕、直式獎勵卡片及橫向配置。
六檔難度分別影響生命、傷害、增援、移速、彈速、預警、精英、波間回血與結算。
電腦保留鍵盤、方向鍵、滑鼠拖曳；畫布跟隨視窗尺寸調整。
可關閉粒子與震動，音效預設關閉。敵人、彈幕、危險區與特效有數量上限。
封面與 Boss 是原創生成式美術，小怪採可辨識的方向／能力幾何標記。
已通過遊戲邏輯、模擬操作與平衡檢查，尚未執行真實瀏覽器及手機實機驗證。
完整驗證範圍請見「測試紀錄.md」。

模式與效果
自訂遠征：分段探索與構築。無盡：每 8 波提升壓力，額外 Boss 耐久 +30%、出招 +20% 封頂。
每日：台灣日期固定種子，輪替流星轟炸、電離彈道與蜂群護衛主題。
設定可選自動／完整／輕量／關閉演出，另可關閉震動和粒子；效果不改變戰鬥規則。
系統減少動態會取消鏡頭震動與縮放，手機自動降低演出負擔。

程式碼
所有 JavaScript、HTML、CSS 與檢查腳本均已換行和縮排。
主要邏輯有中文註解，程式導覽說明重要函式、平衡參數與修改範例。
離線包：index.html、game.js、CSS、assets、操作說明、程式導覽、測試紀錄與 tests。
若已安裝 Node，可在解壓縮後的根目錄執行：
node --test tests/*.test.cjs
node tests/ui-smoke.cjs
node tests/balance.cjs difficulties

舊 Boss 首次讀檔套用新版耐久，保留本體／護盾各自剩餘比例；玩家裝備與生命保持。
新版本不會覆蓋原本保存的自訂方案。
