# 星夜突圍 v1.2｜Blue World 整合版操作手冊

本整合版公開顯示 1.2，保留來源 v1.5 的全部玩法。Boss 耐久與攻擊壓力依接戰等級及裝備成長，包含模式專屬規則、衝擊波與可調整的畫面震動。要體驗完整的新「巨獸試煉」，請重新點選方案再開新局；已保存的舊局不會自動替換你的自訂設定。

## Blue World r11 新介面

- Boss 狀態在戰場上方的獨立精簡列，本體與防護罩並排，不會蓋住攻擊預警。
- 按「戰況 ⓘ」會暫停並顯示完整血量、防護罩、充能及接戰配置。關閉後按「繼續航行」，不會自動開戰。
- 起始武器欄可點「點此展開」，再次點擊收合；鍵盤可聚焦後按 Enter 或 Space。
- 返回遊戲館會暫停並嘗試保存，再次進入可繼續原遠征。重新整理時仍可在首頁選擇「繼續上次遠征」。
- 不同網域、瀏覽器或裝置的存檔不會自動搬移，請使用「設定與備份」匯出／匯入 JSON。

星艦會自動瞄準與開火。你主要負責移動、收集經驗、避開預警，以及選擇適合的強化。

## 1. 開啟與第一次出航

線上版由 Blue World 小遊戲專區進入。離線版解壓縮完整網站，再開啟網站 `index.html`，不要只搬走遊戲 HTML；程式、樣式、圖片與共用字型都需要保留。

手機建議使用線上版，部分手機檔案預覽器無法執行本機網頁程式。

1. 選星艦。
2. 選「輕鬆出航、經典遠征、星海長征、巨獸試煉」其中一個方案。
3. 選波數、難度與模式。
4. 想換起手，就展開「起始武器與配置」。
5. 想自訂敵潮／Boss，再展開對應分類。
6. 按「開始出航」。有未結束的遠征時，遊戲會先提示是否結算舊局。

方案只調整航行規則，保留已選的星艦、起始武器與難度。新的巨獸試煉為 8 波、每波 Boss、30 秒登場、適中敵潮、高頻精英、強化耐久、快速出招、密集彈幕、堡壘護盾、三階段及換階段恢復。它比經典遠征更吃構築與走位。五類進階設定預設收合，每次只展開一類，設定會保存在目前瀏覽器。

## 2. 電腦操作

| ---------- | -------------------- | ------------------------------------------ |

## 3. 手機與平板操作

- 左手在戰場左側按住並拖曳，像搖桿一樣移動；放開停止。
- 右手按右下的衝刺與過載，可以一邊移動一邊使用技能。
- 第二根手指不會取代正在移動的手指。
- 也支援在戰場空白位置拖曳移動。
- 原地衝刺沿最後移動方向；正在移動時沿當前方向。
- 橫向與直向使用不同配置，戰場會配合視窗大小調整。
- 技能按鈕顯示冷卻剩餘時間；未就緒或選擇獎勵時不能使用。
- 切到其他 App 或背景會暫停；回來後按繼續。

## 4. 衝刺與過載怎麼用

衝刺可穿越危險區或拉開包圍，但要留意結束位置。游隼基礎冷卻 2.4 秒，其他星艦 3.2 秒；短暫無敵約 0.55 秒，位移約持續 0.24 秒。推進器模組及時空羽翼遺物能縮短冷卻。

過載基礎冷卻 25 秒，傷害周圍敵人、暈眩短暫時間並清除附近敵彈。暴風蓄電池遺物可擴大範圍、增加傷害並將冷卻縮到 17.5 秒。它不會直接移除已鎖定的地面危險區。

## 6. 波次、Boss 和過關條件

右上「擊破 X / Y」是本波主要目標。起始目標 10–160 隻，可固定，或每波 +3，最多比起始目標多 60 隻。時間經過不會直接換波。

- 普通波：達成小怪擊破目標即可過關。
- Boss 波：達成小怪目標，並擊敗該波 Boss 才過關。
- 先達成目標：仍要等倒數結束、接戰並擊敗 Boss；等待登場時小怪增援減緩；Boss 活著時恢復持續增援，達成目標也不減速。
- 先擊敗 Boss：仍需完成剩餘小怪目標。
- Boss 不計入小怪目標；分裂幼體、召喚護衛、精英被你擊破時會計入。
- 自爆機自行引爆、敵人離開戰場，不計入你的小怪擊破數。
- 額外任務是可選晶礦獎勵，不是主要門檻。

Boss 登場倒數可選 15–180 秒，預設 45 秒，從該波開始累計實際戰鬥時間。暫停、升級、事件與商城不計時。倒數結束才生成，最後 5 秒有警示。

| 出現規則     | 實際行為                                 |
| ------------ | ---------------------------------------- |
| 固定間隔     | 每隔 1–12 波登場，可另追加最後一波 Boss  |
| 每波 Boss    | 每一波倒數結束後登場；不顯示「每隔幾波」 |
| 只在最後一波 | 只在選定總波數的最後一波登場             |
| 不出現 Boss  | 所有波只需小怪擊破目標                   |

無盡模式沒有最後一波，因此選「只在最後一波」會沒有 Boss。間隔值在其他模式會保留但隱藏，切回固定間隔時才再次顯示。

Boss 的耐久、階段、頻率和密度分開調整：

- 耐久：常規、強化總耐久預算 +35%、霸主 +70%；後兩者接觸傷害也增加。
- 二階段：可關閉；開啟時生命低於 50% 進入狂暴。
- 終焉階段：可另外開啟；生命低於 30% 啟動，需先開二階段。
- 頻率：控制招式間隔，舒緩／標準／快速／連攻。
- 密度：控制彈數、禁區與護衛數量，稀疏／標準／密集／極密。
- 難度決定 Boss 的總耐久預算、裝甲、護盾、出招頻率、彈量、連攻層數與接戰增援。實際數值再依接戰時的玩家等級與裝備調整；自訂頻率／密度另乘。
- 不再套用舊版固定數千生命與波數倍增。下一隻 Boss 才依最新構築調整；目前正在打的 Boss 不會因你升級而補血。
- 頻率倍率：舒緩 ×0.7、標準 ×1、快速 ×1.4、連攻 ×1.8。密度倍率：稀疏 ×0.65、標準 ×1、密集 ×1.45、極密 ×1.9。

### 防護罩與本體

青條是防護罩、紅條是本體。護盾存在時所有武器先扣護盾，本體免傷，減速／暈眩也被擋住。破盾那一擊的多餘傷害不會穿透，本體從下一次命中開始受傷。Boss 身上的青色外圈及菱形標記表示有盾，畫面會提示「本體護盾保護／可攻擊」。

| 護盾設定 | 最大護盾                                    |
| -------- | ------------------------------------------- |
| 關閉     | 0，本體可直接攻擊                           |
| 依難度   | 本體最大生命的 12%／20%／27%／34%／42%／50% |
| 輕型     | 本體最大生命的 25%                          |
| 重型     | 本體最大生命的 70%                          |
| 堡壘     | 本體最大生命的 115%                         |

| 恢復設定       | 實際行為                                                        |
| -------------- | --------------------------------------------------------------- |
| 不恢復         | 初始護盾破掉後不再恢復                                          |
| 換階段恢復     | 進入二／三階段恢復原最大護盾的 55%；深淵、災厄為 70%            |
| 階段＋限次充能 | 除階段恢復外，破盾後 24 秒恢復原最大護盾的 35%，每階段最多 2 次 |

恢復的比例以原最大護盾為基準，不是本體剩餘血量。已完成的充能次數會存檔，重新開啟不能洗回次數。選不恢復可一破到底；關閉二階段也會關閉三階段，但不會替你關閉定時充能選項。

Boss 本體有依難度增加的裝甲減傷。減速對 Boss 的持續時間縮至 35%，減速幅度為 20%；單次暈眩最多 0.2 秒，爆炸震退也比小怪小，不能靠冰晶與新星永久壓住巨獸。

不要只一路向同一方向跑。看彈環間隙切入，紅圈鎖定後再橫向移動；把衝刺留給彈幕與轟炸重疊的時刻。過載能清掉附近敵彈，但不能移除地面預警。召喚護衛既是威脅，也是取得經驗與新構築的來源。

### 接戰等級與裝備如何影響 Boss

Boss 在出場時記錄玩家等級、武器種類／等級／進化、傷害與攻速能力、研究、遺物及防禦配置。等級採線性成長，裝備火力採較緩的 0.80 次方成長，讓升級的輸出提升仍然超過 Boss 成長。火力是依武器特性估算的指標，不是實測 DPS，也不會讀取玩家操作或勝率。

玩家目前殘血不影響計算；提高最大生命、減傷與回復只會小幅提高 Boss 攻擊倍率，額外適應倍率有上限。等級成形後，Boss 也會增加出招、彈量及彈速、縮短預警。原始難度和你選的頻率／密度仍有各自影響。

**接戰後數值固定。** 中途撿經驗、買到裝備或進化，會讓你更快擊破目前 Boss；牠不會立刻補血追平。下一隻 Boss 才重新計算。低等級（Lv.1–3）且火力指標低於 65 時，額外連攻少一重；災厄仍有雙重攻擊，狂暴後三重。

Lv.1 游隼、原始脈衝、沒有研究／模組，使用巨獸試煉的「強化耐久、堡壘護盾、三階段、階段恢復」時，生成數值如下。這是出場時的參考；如果已經升級或換武器，實際數值也會改變。

| 難度 | 本體生命 | 初始護盾 | 所有階段合計耐久預算 |
| ---- | -------: | -------: | -------------------: |
| 休閒 |      171 |      197 |               約 584 |
| 標準 |      223 |      256 |               約 767 |
| 困難 |      283 |      325 |               約 985 |
| 噩夢 |      350 |      402 |             約 1,236 |
| 深淵 |      386 |      444 |             約 1,516 |
| 災厄 |      459 |      528 |             約 1,826 |

堡壘護盾仍有 115% 本體生命，但會從同一總耐久預算分配，所以本體相對變薄；開三階段或限次充能，也會預先降低本體份額。原本 Lv.1 動輒數千、甚至上萬的固定耐久已移除。表中的耐久預算計入本體裝甲與恢復盾，因此與兩條血量相加不同；四捨五入與本體最低 70 生命可能造成少量差異。

受傷後保護依序為 0.75／0.72／0.66／0.59／0.52／0.45 秒，衝刺仍有 0.55 秒無敵。困難起額外連攻增加，噩夢起有曲線彈幕，深淵與災厄再疊地面封鎖。最低預警 0.4 秒，實際招式通常更長。

關閉精英仍然有效，Boss 自帶護衛則保留。耐久、頻率、密度、護盾與階段可分別調整，難度不會偷偷改動你的設定。

初次可選休閒／標準＋經典遠征。新的巨獸試煉預設重盾與密集連攻，屬於挑戰方案；想拆招練習，可另選舒緩頻率、稀疏彈幕、單階段、無恢復護盾。

## 8. 判讀戰場與敵人

生命條表示存活狀態；下方經驗條是下一次升級進度。Boss 顯示本體、護盾的數值／血條、階段與目前連攻招式。Boss 離開視野時，有邊緣方位提示。

紅圈、紅線是即將發生的攻擊；黃色瞄準線是散射炮艇蓄力，先離開再接近。Boss 的發光核心是命中／碰撞區，翼刃與外裝甲只是視覺呈現。

| 小怪     | 能力與處理方式                                       |
| -------- | ---------------------------------------------------- |
| 偵察機   | 常規追蹤，練習繞圈與拾取                             |
| 疾行機   | 高速靠近，留衝刺避包圍                               |
| 重裝機   | 高生命，移動較慢，先拉開再打                         |
| 狙擊機   | 預警後射高速彈，別站在瞄準線上                       |
| 衝鋒機   | 蓄力後沿鎖定方向突進，橫向離開預警                   |
| 分裂體   | 擊破後分成兩隻幼體                                   |
| 幼體     | 小、脆、移速高，注意群聚                             |
| 盾衛     | 受到傷害減少 30%，拖住你的火力                       |
| 修復機   | 每 5 秒修復附近最多三名小怪，不能修復 Boss           |
| 自爆機   | 靠近後停下，基礎 1.25 秒預警後爆炸；擊殺後紅圈仍有效 |
| 散射炮艇 | 黃線蓄力後射三方向彈幕                               |

小怪數量可選稀疏、適中、密集、海量；編隊可選綜合、高速、遠程、重裝、分裂蜂群。綜合逐波解鎖，專門編隊從第 2 波起提前加入對應種類。

第 3 波起，精英上方的「甲／速／爆／癒」代表裝甲、迅捷、爆裂、再生。第 6 波起部分精英升格為冠軍，雙重外圈、更高生命與接觸傷害，擊破獲得更多晶礦。

## 9. 經驗、構築與進化

擊破掉落發光晶體，靠近吸入後取得經驗。磁力打撈增加拾取範圍與經驗收益。升級暫停戰鬥，選一項武器、能力或補給；重抽券有限。

最多同時裝備六種武器，每種最高 Lv.5。武器達 Lv.5 且對應能力達 Lv.2，就能在升級或商城獲得進化。

| 基礎武器      | 所需能力 Lv.2 | 進化       |
| ------------- | ------------- | ---------- |
| 脈衝連射 Lv.5 | 超頻迴路      | 雙子湮滅炮 |
| 軌道刃 Lv.5   | 偏轉護盾      | 星環絞碎者 |
| 連鎖電弧 Lv.5 | 弱點解析      | 雷霆網路   |
| 震盪新星 Lv.5 | 裝甲擴建      | 零點超新星 |
| 追獵導彈 Lv.5 | 反應爐增壓    | 蜂巢天火   |
| 冰晶散射 Lv.5 | 磁力打撈      | 永夜冰河   |

每 4 波可以選遺物與下一個星域。遺物維持到本局結束，可以組合加成。部分波有事件：生命／晶礦／強化之間取捨。

4 秒內擊破下一個敵人可延續連鎖，每 20 連鎖有額外晶礦。額外任務和戰場補給箱能增加資源；補給箱靠近取得，可能是晶礦、醫療或磁力吸收。

## 10. 商城、基地與晶礦

波間商城使用本局晶礦購買武器、能力、進化核心、遺物、護盾、重抽券。每件商品只能買一次，可付費更新，更新費用逐次提高。25 晶礦能回復 40% 最大生命。

未使用晶礦在死亡、通關或撤退時，依設定倍率帶回基地。無 Boss 規則另乘 0.85、每波 Boss 另乘 1.20，其他規則乘 1；出航頁顯示實際倍率。通關額外獎勵按總波數比例計算，短局不會取得完整長局獎勵。

基地研究與模組使用已結算晶礦。研究最高每項五級，模組解鎖後永久保留，一次出航裝備一個。研究／模組更動只從下次出航生效，不會改變正在進行的遠征。

| 模組       | 出航效果                            |
| ---------- | ----------------------------------- |
| 深空打撈艙 | 磁力打撈 Lv.1，起始晶礦 +15         |
| 生命循環艙 | 奈米修復 Lv.1，生命 +12             |
| 躍遷推進器 | 速度能力 Lv.1，衝刺冷卻 −15%        |
| 紅線反應爐 | 傷害能力 Lv.1，生命 −10%            |
| 黎明護盾   | 護盾能力 Lv.1，每波開始獲得一次護盾 |

特殊航線「超頻、打撈、紅線」的利弊會額外套用。紅線生命削減在模組調整後計算，出航預覽會顯示最終數值。

## 11. 存檔、離開與跨裝置

戰鬥每 10 秒自動保存，暫停、保存離開及選擇獎勵後立即保存。切到背景會暫停；再次開啟按「繼續上次遠征」，先顯示暫停畫面。

「保存離開」之後可繼續；「結算撤退」會結束本局。開始新局也會提示結算舊局。死亡／通關／撤退只結算一次，結算後不能再回該局。

進度保存在目前瀏覽器，沒有跨裝置自動同步。線上版、本機版、不同瀏覽器與裝置的進度互相獨立：

1. 舊裝置打開「設定與備份」，匯出 JSON。
2. 新裝置或新版離線資料夾打開遊戲。
3. 匯入 JSON，確認取代新裝置上的進度。

v1.5 保存接戰配置、護盾剩餘量、已用充能次數、護衛計時及正在連發的攻擊，暫停與升級期間凍結。舊 Boss 第一次讀檔會換成新版耐久，但保留本體與護盾各自的剩餘比例；破掉的護盾不會免費補滿。之後再次讀檔不會重算。玩家的研究、武器與生命保持原值。自訂方案不會被新版覆蓋，要套用完整巨獸試煉方案請重新選擇並開新局。

清除瀏覽器資料或換資料夾前先備份。舊研究、成就、晶礦、武器、生命和商城狀態可以保留。v1.0／v1.1 缺少本波擊破數，升級後該波從 0 開始；v1.2 以後已保存的擊破進度可完整還原。

## 12. 三種模式的差異

| 模式         | 實際戰鬥差異                                 | 成長方式                                                         |
| ------------ | -------------------------------------------- | ---------------------------------------------------------------- |
| 自訂遠征     | 分段星域、航線、事件與商城構築，完成選定波數 | 每隻 Boss 依最新等級及裝備接戰                                   |
| 無盡星域     | 沒有最後一波，星環顯示持續壓力               | 每 8 波提升一級，最多五級；Boss 額外耐久最多 +30%、出招最多 +20% |
| 每日種子遠征 | 台灣日期固定種子，輪替以下三種主題           | 相同設定與相同操作序列可重現同一結果                             |

每日流星航道有離子暴雨與延遲流星轟炸；電離星潮加入遠程編隊與微彎 Boss 彈道；蜂群潮汐的非 Boss 波為蜂群波，Boss 召喚更多弱小幼體、疾行機與分裂體。主題除了配色，還會實際改變敵潮及 Boss 攻擊。

無盡的額外壓力有上限，玩家等級與裝備仍會影響後續 Boss；上限不是固定所有怪物的生命，也不會停止正常構築成長。

## 13. 演出與效能設定

| 演出選項 | 畫面效果                                                   |
| -------- | ---------------------------------------------------------- |
| 自動     | 電腦完整，手機／窄螢幕輕量                                 |
| 完整     | 能量弧光、彈尾、光束白芯、更多粒子與少量鏡頭縮放           |
| 輕量     | 減少粒子與發光，保留震波、攻擊形狀與預警                   |
| 關閉演出 | 關閉新增鏡頭／能量演出，仍保留基本命中效果、子彈與攻擊預警 |

畫面震動與粒子可以另行開關。系統「減少動態」會取消鏡頭震動與縮放，效果選擇不改變碰撞、彈量或遊戲速度。手機震動幅度較低；暫停畫面不再持續晃動。

四種 Boss 的演出不同：裂隙吞噬者為破裂弧光，鋼鐵暴君為雙層熔核震波，星雲女皇為結晶法陣，永夜核心為反轉星環與十字脈衝。破盾、換階段、過載與擊破有不同衝擊。所有紅色危險輪廓在最後繪製，避免被光效遮住。

音效預設關閉，可在上方或設定中開啟。破盾、高能衝擊與狂暴使用不同音效；同類音效有節流，避免密集攻擊堆疊音量。敵人、彈幕、危險區與特效都有上限，視野外特效不繪製。
