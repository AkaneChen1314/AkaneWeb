## 6.1 CROSSFIRE 貼牆射擊與首領節奏

- 移除附近有障礙就停用射擊的限制。貼牆仍可連射、正常消耗彈藥與自動換彈；擋住彈道的實際牆面會承受子彈。
- 子彈先取得視線目標，再由安全槍口檢查彈道；攝影機至槍口之間的薄牆、轉角也會攔截，避免從牆後出彈。移動用的鐵網及保守碰撞盒不再變成隱形彈道障礙，地面與閘桿也有實體命中。
- 快取剛性槍身的模型邊界，靠近掩體立即收槍、離開後平順復位，極近距離改用可見的抬槍姿勢；側邊掩體不再強制退出瞄準，正面過近時才收起瞄具，並使用防抖區間避免來回切換。射線判定在攝影機後座之前執行。
- 首領輪替精準轟擊、兩／三段連續轟擊及扇形震波。落點固定且預先顯示，連段區域保留可通行的空隙；震波有青色安全缺口，也能以跳躍越過。
- 首次大招提前至接敵後約 2.6 秒準備；每次大招後弱點開放 1.9 秒（第二階段 1.7 秒），停止移動與射擊。青色核心、血條及提示音標示反擊窗口，身體傷害為基礎 1.4 倍、頭部為 1.9 倍，未增加首領血量。
- 小地圖標示每一個連段預警與震波安全缺口，手冊同步更新。

## 6.0 WARLORD 擴充與效能修正

- 四種任務：原有全面肅清、波次攻堅、限時獵殺，加上兩階段「首領討伐」。先清除護衛，3.2 秒整備後迎戰指揮官，並獲得生命、護甲、75 發備彈與一枚手榴彈補給（各項不超過上限）。
- 可在大廳設定常規敵軍數量（建議／6／12／18／24／30）、額外強度（0.80／1.00／1.25／1.50）、菁英比例（無／約 15%／約 25%／約 30%），並在肅清或波次模式追加首領。討伐模式至少約 25% 菁英，選單同步顯示生效比例。波次選擇的是最後一波人數，前兩波依比例遞增；首領另計 1 名。限時模式會同步調低較小戰局的擊殺目標。
- 一般敵軍具有突擊、側翼與射手角色；菁英有青藍裝甲與加強戰術；指揮官有較大的重裝模型、頭部弱點與獨立血條，基礎 700 生命，受難度及強度設定影響。半血進入第二階段，範圍攻擊更快、更大；攻擊先標記位置，能移開或躲在厚實掩體後。
- 首領預警會凍結在最初標記位置，不會持續追蹤玩家；暫停同步凍結，首領死亡或任務結束後會清除未完成攻擊。敵軍統計涵蓋尚未登場的首領，小地圖分辨一般、菁英與首領。
- 大廳改為固定部署按鈕與獨立捲動內容，設定收進可展開區塊，避免把封面塞滿；暫停時也能即時調整主音量、畫質並查閱手冊。新配置、模式、難度與混音設定會在瀏覽器工作階段保留。
- 新增戰鬥、環境、提示三組音量。預設為 80%／35%／55%，加上主音量 72%；限制同時瞬間音源至 24 個，保留玩家槍聲與換彈優先權，降低密集敵軍槍聲、彈殼尾音及連鎖爆炸低頻的堆疊。修正左右定位與環境循環接縫。
- 修正低幀率使換彈及手榴彈變慢的問題，以不超過 0.05 秒的子步更新戰鬥；超過 0.5 秒的嚴重停頓會安全暫停，並補償任務計時。
- 玩家依實際位移播放腳步；衝刺碰撞細分，防止穿薄牆；補上跳躍撞頂、落在低掩體及首領較大體積的碰撞。補到彈藥時，空槍也會自動換彈。統一庫存上限，修正波次及連殺補給反而扣掉高庫存彈藥／手榴彈的問題。
- 共用曳光、彈殼及火花幾何，為瞬間特效設上限；粒子阻力及攝影機復位依時間計算，陰影深度更新依畫質節流，槍口火焰仍逐幀繪製。

## 執行方式

網站整合版已提供 `browser.js`，包含3D模組、玩法與八種音效。可以直接雙擊本遊戲的 `index.html`，也可以從 Blue World 遊戲館或 GitHub Pages 開啟，不需安裝 Node.js、不必啟動伺服器。

需要鍵盤滑鼠與支援 WebGL 的瀏覽器。Esc 暫停並釋放滑鼠；若瀏覽器不允許鎖定滑鼠，可在暫停選單使用拖曳視角。

以下本機伺服器方式保留供開發測試，屬可選工具：

```text
開始遊戲.cmd
```

或由 PowerShell 執行內建伺服器：

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -OpenBrowser
```

然後前往 <http://localhost:4173>。

## 操作

- `W A S D`：移動
- 滑鼠：瞄準
- 滑鼠左鍵：射擊
- 滑鼠右鍵：機械瞄具
- `Shift`：衝刺
- `Space`：跳躍
- `R`：換彈
- 按住 `G`：預覽手榴彈，放開投擲；預覽時左鍵取消
- `Esc`：暫停／解除滑鼠鎖定

> 玩家不需要打包工具。Three.js原始模組保留於vendor，發布頁使用已產生的browser.js。

### 修改來源後重新打包

修改main.js、玩法模組、browser-entry.js或音效後，需要以官方esbuild **0.28.2**重新產生browser.js。將執行檔路徑傳入：

```powershell
node .\build.mjs C:\tools\esbuild.exe
node .\tests\direct-startup.mjs
```

build.mjs會核對工具版本，並將模組與data URL音效打包為傳統IIFE腳本。browser.js必須和index.html一起提交；GitHub Pages發布現有檔案時不需安裝或編譯。
