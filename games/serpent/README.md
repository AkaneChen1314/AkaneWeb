# 霓境蛇行 / Neon Serpent

一款以貪吃蛇成長機制結合生存競技與隨機進化的單人遊戲。原創程式化 3D 角色、場景與合成音樂；沒有外部套件、廣告或付費內容。

## 開始遊戲

在 Blue World 小遊戲專區選擇「霓境蛇行」，查看玩法後按開始；也可透過網站直接開啟本資料夾的 **index.html**。無須啟動自己的伺服器。

此為網站整合副本，中文字型取自網站的 `../../shared/fonts.css` 與 `../../assets/fonts/`；原始桌面「貪吃蛇」資料夾保留不變。返回專區會暫停模擬與音訊，同次開啟可重新進入並手動繼續。

建議開啟瀏覽器硬體加速，獲得完整 3D 效果。WebGL 不可用時會切換為相容畫面；音訊在首次互動後才會啟動。設定內可降低畫質、關閉音效、減少動態效果，以及切換操作方式。

第一次玩請點大廳的 **八步無傷練習**，依序練轉彎、收集、衝刺、自動咬擊、衝撞、纏繞、技能與進化。練習不會死亡，也不發獎勵、不寫入紀錄。完整文字版規則見 [完整遊戲規則.md](完整遊戲規則.md)，遊玩中按 **H** 也能查閱。

## 玩法

三個按鍵就能玩：**移動、衝刺、技能**。咬擊是自動的，敵人進入蛇頭前方就會被咬。

| 操作         | 電腦                            | 手機 / 觸控  |
| ------------ | ------------------------------- | ------------ |
| 移動         | 滑鼠或 WASD／方向鍵（自動切換） | 左下搖桿     |
| 衝刺撞擊     | 按住 Space／Shift／滑鼠左鍵     | 按住衝刺按鈕 |
| 專屬技能     | E／滑鼠右鍵                     | 點技能按鈕   |
| 大地圖       | M 或點小地圖（遊戲暫停）        | 點小地圖     |
| 暫停 / 繼續  | Esc 或 P                        | 右上暫停按鈕 |
| 查看完整規則 | H                               | 點「規則」   |
| 選進化       | 1 / 2 / 3 或點選                | 點選強化     |

三種攻擊：

- **自動咬擊**：目標進入前方扇形就咬，40 傷害。
- **衝刺撞擊**：按住衝刺撞上敵人，70 傷害並把小蟲撞飛。
- **纏繞絞殺**：繞一圈讓蛇頭碰到自己的身體，圈內敵人受重創、食物一次吸光，圈越大越痛。

**生命歸零才死亡。只有蛇頭會受傷，而且只有敵人能傷你**；牆壁、岩石與地標只會擋路並讓蛇頭沿邊滑開，岩石還能擋子彈。

## 地圖、食物與小地圖

- 地圖長寬為 v4 的 2 倍（競技場 168 × 168、其他模式 252 × 252），物件依面積重新計算。
- 大廳的「遊戲說明」：五頁圖示卡片（怎麼玩／地圖／危險／食物道具／敵人首領），依目前選的模式與難度顯示；遊戲中暫停後可開「本局說明」。不會在開始前自動跳出。
- 升級與結算選單有防誤觸保護：剛跳出時短暫不接受輸入，空白鍵不會選卡。

- 地圖元素：治癒泉、加速板、成對傳送門、晶簇寶箱、四座地標，以及每個世界專屬的泥沼／冰面／流沙。
- 食物：能量球、星光果、進化晶體、生命十字，加上六種道具（疾風羽、磁暴核、怒焰椒、護盾泡、爆裂果、彩虹果）。食物總量約為舊版的 40%，成群出現；道具有數量上限並會在 45 秒後消失。
- 小地圖：顯示你的位置與方向、目前畫面範圍、敵人、首領、道具、寶箱、治癒泉、傳送門與地帶。畫面外的首領與道具會以邊緣箭頭標示距離。

## 難度、怪物與首領

- **難度**：普通／中等／困難。改變怪物種類（5／8／10 種）、敵人血量與速度、你受到的傷害、預警時間與得分倍率；中等以上會出現精英怪。
- **10 種怪物**：斥候蟲、追獵蟲、砲擊蟲、群蜂、分裂蟲、衝鋒甲蟲、自爆蟲、盾甲蟲、巫蟲、狙擊蟲，各有不同的行為與應對方式。
- **三位首領**：各有三個階段與四種招式（震地、地裂、落石雨、熔岩怒吼／召喚蟲群、毒霧、螺旋彈幕、女王之盾／雷霆突進、落雷、雷射掃射、電磁環），每次換階段會怒吼並放出能量環。登場時有標題畫面，血條顯示階段與目前招式。

## 模式與進度

- **蟲群對戰**：四波殲滅，共 5／7／9／12 隻。
- **首領連戰**：依序挑戰裂地守衛、孵巢女王、雷霆暴君。
- **無盡狂潮**：沒有結束倒數，每 60 秒安排一位首領。
- **荒野生存**：撐過 180 秒，120 秒時首領出現。
- **極速獵食**：120 秒收集挑戰，食物更多、吞噬得分 1.5 倍。
- **悠遊秘境**：無限時間、沒有敵人、不受傷害。
- **進化研究所**：晶體購買永久生命、吸附與經驗加成，每項 5 級。
- **冒險紀錄**：最高分、最近 15 局（含難度）、11 種成就。

進度儲存在目前瀏覽器的 localStorage，沿用 `neon-serpent-v1` 存檔，舊的晶體、強化與成就都會保留。

## 檔案

- `index.html`：選角、遊戲畫面與介面結構。
- `styles.css`：桌機與手機介面、操作回饋、小地圖與減少動態效果。
- `engine.js`：與畫面獨立的遊戲模擬：碰撞、攻擊、地形、食物、敵人、進化與存檔資料規則。
- `renderer.js`：原創網格模型、光照、地形與道具造型、WebGL 實例化繪圖與相容繪圖模式。
- `app.js`：操作、音訊、特效（光暈、打擊停頓、震動、邊緣指示）、小地圖、介面狀態與遊戲迴圈。
- `guide.js`：七章遊戲內規則手冊與示意圖。
- `完整遊戲規則.md`：供玩家閱讀的完整規則說明。
- `tests/*.test.cjs`：規則測試（`enemies.test.cjs` 涵蓋難度、怪物與首領）；`tests/瀏覽器測試.html` 可在沒有 Node 的電腦上用瀏覽器執行同一組測試。

## 開發與驗證

在本資料夾啟動本機伺服器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

- 遊戲：`http://127.0.0.1:4173`（加上 `?debug` 可在主控台用 `__serpent.game()` 檢查遊戲狀態）
- 測試：`http://127.0.0.1:4173/tests/瀏覽器測試.html`
- 有安裝 Node 時也可執行 `node --test tests/*.test.cjs`

效能控制包含固定步長模擬、WebGL 實例化、鏡頭外物件裁減、粒子/敵人/蛇長上限、小地圖地形快取、像素倍率上限，以及離開分頁自動暫停。
