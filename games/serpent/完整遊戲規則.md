# 霓境蛇行｜完整遊戲規則

這是一款單人、自由轉向、生命值制的戰鬥貪吃蛇。敵人由電腦控制。生命歸零才死亡；身體被碰到不會被吃掉，牆壁與岩石也不會扣血。

## 先學操作：三個按鍵就能玩

| 動作     | 電腦                                                            | 觸控       |
| -------- | --------------------------------------------------------------- | ---------- |
| 移動     | 移動滑鼠，或 WASD／方向鍵（兩種自動切換，最後動到哪個就用哪個） | 左下搖桿   |
| 衝刺撞擊 | 按住 Space／Shift／滑鼠左鍵                                     | 按住衝刺鈕 |
| 專屬技能 | E／滑鼠右鍵                                                     | 技能鈕     |
| 咬擊     | **自動**：敵人或寶箱進入蛇頭前方扇形就會咬                      | 自動       |
| 大地圖   | M，或點右下小地圖（遊戲暫停）                                   | 點小地圖   |
| 進化選擇 | 1／2／3 或點卡片                                                | 點卡片     |
| 暫停     | Esc／P                                                          | 右上暫停鈕 |
| 完整規則 | H                                                               | 規則鈕     |

大廳上方的**遊戲說明**用五頁圖示卡片快速介紹：怎麼玩、地圖物件（不會扣血）、危險（會扣血）、食物道具、本局會遇到的敵人與首領；左右方向鍵可以翻頁。它不會在開始前自動跳出，想看再打開；遊戲中按 Esc 暫停後可以開「本局說明」。

**升級選單防誤觸**：選單跳出後約 0.65 秒內不接受點擊與按鍵（上方有進度條），而且空白鍵、Enter 不會選卡。用 1／2／3 或滑鼠點選；鍵盤玩家也可以先用方向鍵或 Tab 移到卡片再按 Enter。結算畫面同樣有短暫保護，空白鍵不會誤按「再來一局」。

蛇會一直前進，放開方向也不會停下。查規則、看大地圖、暫停、選進化、切換到其他分頁時，遊戲會暫停。設定裡可以把操作改成「只用鍵盤」或「滑鼠跟隨為主」。

大廳有「八步無傷練習」：轉彎 → 吃五顆 → 衝刺 → 自動咬中靶 → 衝撞中靶 → 繞圈纏繞靶 → 技能 → 進化。練習靶只接受指定攻擊。練習沒有傷害、不發獎勵、不寫紀錄。

## 怎麼攻擊

| 招式     | 怎麼發動                                              | 基礎傷害與限制                                                                                |
| -------- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 自動咬擊 | 目標進入蛇頭前方 120 度、距離 3.8（加目標體積）的扇形 | 40 傷害，每 0.5 秒最多一次；有目標才咬，不耗能量                                              |
| 衝刺撞擊 | 按住衝刺時，蛇頭撞到敵人的頭或身體                    | 70 傷害並把小蟲撞退，同一敵人每 0.7 秒最多一次                                                |
| 纏繞絞殺 | 蛇長 14 節以上，讓蛇頭碰到自己後段的身體圍成一圈      | 圈內每隻敵人受到 120 + 圈長 × 3 傷害；寶箱直接破裂，圈內食物全部吸收；同時圈住 2 隻以上另加分 |
| 蛇身反擊 | 敵人頭部碰到頭後第 5 節以後的蛇身                     | 25 傷害，同一敵人每 0.9 秒最多一次；你不受傷                                                  |
| 環繞光刃 | 自動                                                  | 每顆每秒 45 傷害                                                                              |

附近有目標時，蛇頭前方會出現虛線扇形，提示自動咬擊的範圍。赤焰初始傷害 ×1.2；「能量增幅」每次 ×1.3；怒焰椒 8 秒內 ×1.8。

衝刺速度 1.9 倍，每秒耗 38 能量，放開後每秒恢復 24。耗盡後必須先放開再按。衝刺中撞到敵人頭部不扣血，但子彈與紅圈仍會傷你。

## 受傷與死亡

下表是**中等難度**的基礎傷害；普通 ×0.7、困難 ×1.3。

| 危險                     | 單次傷害                        |
| ------------------------ | ------------------------------- |
| 蛇頭碰普通敵人頭部／核心 | 18 HP（群蜂、小分裂蟲較輕）     |
| 蛇頭碰首領核心           | 30 HP                           |
| 被衝鋒甲蟲撞到           | 22 HP                           |
| 蛇頭被子彈命中           | 14 HP（狙擊彈 22、暴君電球 20） |
| 自爆蟲爆炸               | 24 HP                           |
| 震地紅圈 / 地裂線 / 落石 | 26 / 24 / 20 HP                 |
| 落雷 / 雷射 / 能量環     | 24 / 20 / 20 HP                 |
| 站在毒霧池裡             | 每次 10 HP                      |

只有蛇頭判定受傷，而且只有敵人能傷你。**牆壁、岩石、柱子與地標都不扣血**：蛇頭會沿著表面滑開。岩石還能擋下敵方子彈，是躲彈幕的掩護。

受傷會中斷連擊、縮短最多 3 節（至少保留 8 節），然後給予 1.25 秒受傷保護。護盾泡可以抵擋一次傷害。生命低於 40% 時，畫面邊緣會指出最近的治癒泉。

道具（大地圖最多同時 4 個、小型競技場 2 個；45 秒後消失，最後 5 秒閃爍）：

| 道具   | 效果                               |
| ------ | ---------------------------------- |
| 疾風羽 | 6 秒內速度 +30%，衝刺不耗能量      |
| 磁暴核 | 8 秒內吸附範圍 +9                  |
| 怒焰椒 | 8 秒內所有傷害 ×1.8，咬擊速度加倍  |
| 護盾泡 | 抵擋下一次傷害（25 秒內有效）      |
| 爆裂果 | 吃下立刻爆炸，周圍敵人受到 90 傷害 |
| 彩虹果 | 250 分、14 經驗，蛇身長得更多      |

畫面外的道具與首領會在畫面邊緣以箭頭和距離標示。每 3 成長點長 1 節，最多 160 節。**連擊只算攻擊**：咬擊、衝撞、纏繞、蛇身反擊、技能或爆裂果打中怪物才會累積，吃東西、打寶箱與光刃自動傷害都不算。3 秒內再打中就延續，每 10 連擊擊敗敵人的得分 +10%，最多兩倍；受傷或 3 秒沒打中就中斷。

## 地圖與地形

正式模式的地圖長寬都是 v4 的 2 倍：蟲群對戰與首領連戰 168 × 168，其餘模式 252 × 252。食物、寶箱、治癒泉、加速板、傳送門等依面積增加，密度和之前差不多；敵人與道具仍在你附近出現。大地圖有 8 座地標與 5 組傳送門，競技場有兩圈共 8 根柱子。右下小地圖在大地圖上只顯示你附近約 110 公尺，按 M 看全圖。

| 地形       | 效果                                                   |
| ---------- | ------------------------------------------------------ |
| 治癒泉     | 蛇頭停在泉中每秒恢復 9 HP；泉水用完會慢慢回滿          |
| 加速板     | 經過時 1.6 秒內速度 ×1.5，並補 25 衝刺能量             |
| 傳送門     | 成對出現（同顏色相連），整條蛇一起傳送                 |
| 晶簇寶箱   | 咬擊、衝撞或纏繞打破，掉落能量、晶體或道具（40% 機率） |
| 岩石／地標 | 只會擋路，不扣血；擋得住敵方子彈                       |

三個世界各有專屬地帶：螢光森境的**泥沼**（減速 40%，敵人同樣變慢）、極光冰原的**冰面**（速度 +15% 但轉向滑溜）、赤沙遺境的**流沙**（減速 45%，會被慢慢拉向中心）。大地圖四個角落各有一座地標（巨木／冰晶尖塔／遠古方碑）。

蟲群對戰與首領連戰使用較小的競技場：四根對稱柱子當掩護，另有一座治癒泉、六塊加速板、一組傳送門與四個寶箱。

## 三位首領：三個階段、各四種招式

首領血量降到 66% 與 33% 時進入下一階段：**怒吼 1.3 秒（無敵）**並放出一圈能量環，之後攻擊更快、更多。衝撞首領時蛇頭會被彈開並有 0.5 秒保護，所以「衝撞後閃開」是安全的打法。

1. **裂地守衛・熔岩巨像**（扇形彈幕）
   - 震地：在你的位置與前進路線放置紅圈，填滿後震地。
   - 地裂：裂出數道直線，亮起 1 秒後爆發；第三階段改為全方位。
   - 落石雨（第 2 階段起）：周圍落下大量石塊，每顆都有預警圈。
   - 熔岩怒吼（第 3 階段起）：擴散的熔岩環，按住衝刺可以穿過。
2. **孵巢女王・萬蟲之母**（環形彈幕）
   - 召喚蟲群：在身邊召喚多組小怪。
   - 毒霧：在你附近留下持續 6 秒的毒霧池。
   - 螺旋彈幕（第 2 階段起）：原地旋轉射出螺旋子彈，找縫隙鑽過去。
   - 女王之盾（第 2 階段起）：她召喚的小蟲活著時，女王只受 35% 傷害（血條會變成條紋）。
3. **雷霆暴君・風暴君王**（快速彈幕，後期加上追蹤電球）
   - 雷霆突進：亮出紅色路徑後高速突進，後期連續 2–3 次；結束後暈眩，受到傷害 ×1.5。
   - 落雷：一連串落雷砸向你的位置。
   - 雷射掃射（第 2 階段起）：射出雷射橫掃 120 度；第三階段兩道同時掃。
   - 電磁環（第 2 階段起）：連續放出擴散電磁環，按住衝刺可以穿過。

每位首領掉落補給與道具，另給 20 枚晶體。

## 收集與進化

經驗條滿時暫停，隨機三選一進化；等級越高，下一級需要的經驗增加得越快。新增進化「銳利獠牙」（咬擊範圍 +20%、間隔 −15%）與「纏繞之鱗」（絞殺傷害 +40%）。擊敗敵人與打破寶箱也提供經驗。

## 結算與保存（難度會一起記錄在冒險紀錄）

Esc／P →「結算本局」可領取已得獎勵。挑戰通關額外 +20 晶體（悠遊不算），每 300 分 +1 晶體，新成就各 +10 晶體（「絞殺大師」：單局以纏繞擊敗 10 名敵人；「無畏挑戰者」：在困難難度完成一次挑戰）。

進度保存在本機瀏覽器，沿用舊存檔（晶體、強化、成就都保留）。改版後第一次開始遊戲會再顯示一次新規則說明。
