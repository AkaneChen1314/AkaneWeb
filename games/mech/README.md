# 鋼鐵廢墟：機甲戰線（MECH FRONTLINE）

第三人稱機甲射擊。在機庫依序選好模式、機體、塗裝、主武器、副武器、技能與小兵，出擊後擋住一波波敵軍，迎戰巨型 Boss。

網站入口：[index.html#play=mech](../../index.html#play=mech)。遊戲本體可單獨開啟本資料夾的 `index.html`，左下角的浮動按鈕可回到 Blue World 遊戲館（對戰中自動隱藏）。

## 操作

| 電腦                 | 手機／平板（觸控）                     | 功能                       |
| -------------------- | -------------------------------------- | -------------------------- |
| W A S D              | 左半邊拖曳（浮動搖桿）                 | 移動                       |
| Shift（按住）        | 搖桿推到外圈                           | 推進（消耗能量）           |
| 滑鼠                 | 右半邊滑動；按住武器鈕時滑動也能瞄準   | 轉動視角                   |
| 左鍵／右鍵           | 「主武器」／「副武器」                 | 開火                       |
| Space（按住）        | 「噴射」（長按飛）                     | 跳躍與飛行                 |
| R                    | 「換彈」                               | 換彈                       |
| Q E F／1 2           | 直接點 HUD 下方的技能格與小兵格        | 技能／派出小兵             |
| Z X C                | 直接點強化卡片                         | 每波結束的三選一強化       |
| Esc                  | 左上角「暫停」                         | 暫停                       |
| 機庫中拖曳畫面       | 機庫中手指拖曳                         | 旋轉展示的機體             |

手機請橫放；直拿時會提示把手機橫過來（也可以選擇仍直向遊玩）。觸控只在沒有滑鼠、以觸控為主的裝置啟用，網址加上 `?touch=1` 可以在電腦上強制開啟測試。

## 網站整合

| 檔案                                                          | 用途                                                                                                         |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| [js/portal-bridge.js](js/portal-bridge.js)                    | 返回遊戲館時：對戰中自動暫停、解除滑鼠鎖定、放開按住的按鍵、暫停音樂與音效，並停止 3D 繪製；回來後按「繼續」 |
| [js/touch.js](js/touch.js)                                    | 手機觸控：搖桿、按鈕、技能格與強化卡片點選；小螢幕時機庫與 HUD 等比例縮小                                    |
| [../touch-controls.js](../touch-controls.js)、`.css`          | 三款新遊戲共用的觸控元件（搖桿、視角滑動、按鈕、直向提示）                                                   |
| [../game-portal.css](../game-portal.css)                      | 單獨開啟時的「返回 Blue World 遊戲館」浮動按鈕                                                               |
| [css/style.css](css/style.css) 結尾的「手機觸控」區塊         | 觸控時 HUD 讓位（機體狀態與武器面板移到左上）與等比例縮放                                                    |

- 背景音樂：只讀取 [js/audio.js](js/audio.js) 裡 `MUSIC.files` 列出的 mp3（目前 `battle`、`battle2`、`boss`、`boss2`），沒列出的用內建合成音樂；更換方式見 [music/放音樂的說明.txt](music/放音樂的說明.txt)。
- Three.js 0.147 與後製特效從 jsDelivr CDN 載入（遊戲原本的寫法），離線或 CDN 無法連線時遊戲不會啟動。
- 存檔（機庫配置、最佳紀錄、設定）保存在瀏覽器的 localStorage，網站版與本機檔案版分開。
