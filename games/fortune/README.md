# 運氣戰鬥 · Fortune Siege

**賭場 × 商店 × 塔防 × 收集 × Roguelike**

直接用瀏覽器（Chrome / Edge）打開 `index.html` 就能玩，不需要安裝任何東西。
所有圖像、音效、音樂都是程式即時產生的，沒有用到任何外部素材。

## 遊戲流程

每一波之間可以在三個區域切換（上方分頁，或按 Q / W / E）：

1. **🎰 賭場**：用金幣下注，贏金幣、道具、增益 Buff，還有只能在賭場拿到的「賭場限定塔」。
2. **🏪 商店**：買 ★1 塔，在強化工坊用兩座相同的塔升星，或把不同元素的塔融合成新塔。
3. **⚔ 戰場**：把備戰區的塔拖到地圖上布陣，然後按「開始」打怪。戰鬥中不能離開戰場。

守住 30 波就勝利，之後可以繼續玩無盡模式。

## 🎰 幸運賭場（三區、七種遊戲）

| 區域 | 遊戲 | 玩法 |
|---|---|---|
| 老虎機區 | 命運拉霸 | 3 輪 5 線。可選「拉霸機」（滾輪自動停）或「SLOT」（自己按 STOP 目押）。🌈 彩色球可以變成任何圖案，還能同時在不同連線變成不同圖案。777 進小瑪莉大抽獎，彩色球 ×3 進超級大抽獎，皇冠 ×3 拿限定塔 |
| 老虎機區 | 小瑪莉 | 燈光繞圈停在獎品上：倍率、道具、Buff、限定塔、加回合 |
| 桌台區 | 幸運輪盤 | 兩個分頁：「押顏色／大小」（紅黑、單雙、大小、一打），或「選我的號碼」直接點 0～36（1～36 由左到右排列） |
| 桌台區 | 骰寶大小 | 三顆骰子，押大、小、豹子或點數 |
| 運氣挑戰區 | 翻倍挑戰 | 猜中彩池 ×2，可以隨時收手拿走全部；猜錯就全部歸零 |
| 運氣挑戰區 | 彈珠台 | 選低／中／高風險，彈珠掉在哪一格就拿那格的倍率 |
| 運氣挑戰區 | 刮刮樂 | 用滑鼠刮開九格，三個一樣就中獎 |

- 押注籌碼從 10 到 2500 金。押越多，贏的金幣越多，道具品質也越好。
- 每個遊戲都會直接寫出「這次押注中了可以拿多少」。
- **每個遊戲都有公開的機率表，開獎完全照表抽**：

| 遊戲 | 中獎率 | 說明 |
|---|---|---|
| 命運拉霸 | 約 67% | 贏回押注以上約 49%，大抽獎約 2.1%（約 48 轉一次）。依目前三條滾輪逐一列舉算出精確機率，顯示在賠率表下方 |
| 小瑪莉 | 50.6% | 另有 6% 退回本金。每一格的機率寫在格子左上角和左邊的表（加總 100%） |
| 刮刮樂 | 48.3% | 另有 6% 退回本金，45.7% 沒中 |
| 輪盤 | 紅黑／單雙／大小 48.6% | 一打 32.4%，單一號碼 2.7% |
| 骰寶 | 大／小 48.6% | 豹子 2.8%，點數至少中一顆 42.1% |
| 翻倍挑戰 | 每次 48% | 階梯上寫著連中 1～10 次的機率 |
| 彈珠台 | 低風險 77.4%、中 38.8%、高 14.6% | 風險越高、最大倍率越大。每一格的落點機率都列在右邊 |

- 「幸運值」只會提高小瑪莉 ×20 以上大獎的權重，以及賭輸時的「幸運重來」機率；畫面上的機率會跟著即時更新。
- 全自動：可以自動連玩 10、25 或 50 局。中大獎（30 倍以上）或金幣不夠時會自動暫停。

## 🏪 商店與強化工坊

- 商店只賣 ★1 塔。每波結束會免費刷新，也可以付費刷新。另外還有道具櫃。
- 已經有同一種 ★1 塔時，商店卡片會多一個「**買＋升星**」按鈕，買下後馬上合成 ★2。
- **下方「我的塔」**：列出你擁有的全部塔（還沒放的＋已經在地圖上的），和強化工坊顯示的一致。相同的塔顯示「×2」「×3」，已經放到地圖上的標示「📍 在地圖上」；一頁 10 種，超過時用 ◀▶ 換頁。備戰區最多 24 座。
- **放塔**：點一下備戰區的塔，再點地圖空地就蓋好；同一疊還有剩會繼續選著，可以連續放。選取時可以蓋的空地會亮綠色，可以升星／融合的塔會閃爍外框。右鍵或 ESC 取消。也可以直接拖曳到地圖上。
- **升星**：兩座同種類、同星級的塔可以合成一座高一星的塔。畫面會寫清楚費用，以及傷害、攻速、射程會從多少變成多少。有四種方式：
  - 選取備戰區的塔後，點地圖上相同的塔
  - 把塔卡拖到地圖上相同的塔，或拖到別的塔卡上融合（拖曳時會顯示結果和費用）
  - 「我的塔」左上角出現「⬆★2」時，點一下直接升星（地圖上的塔也算，會原地升級）
  - 點地圖上的塔，資訊卡裡有「⬆ 升星」按鈕，這座塔會原地升級
  - 強化工坊的「⚡ 一鍵全部升星」：從低星開始全部升上去，金幣不夠時會停
- **融合**：兩座不同元素、同星級的元素塔可以融合成雙元素塔，再融合就變成三元素塔。
- 每個星級都有新能力：★2 攻速提升 → ★3 連擊 → ★4 覺醒新星 → ★5 傳說 → ★6 神話天罰，外觀也會一路升級。

## 🏰 55 種防禦塔

- **元素塔（6 種）**：烈焰、寒霜、雷霆、毒霧、疾風、巨岩。
- **職業塔（6 種）**：弓箭塔、狙擊塔（射程超遠）、防空砲（打飛行敵人 2.5 倍傷害）、戰鼓塔（強化周圍的塔）、時光塔（讓敵人變慢）、金礦（每波產金）。
- **賭場限定塔（8 種，只能從賭場拿到）**：招財貓、骰子砲、金蟾、拉霸塔、輪盤砲、王牌、黃金龍，以及傳說塔「幻彩稜鏡」。
- **融合塔（35 種）**：15 種雙元素塔、20 種三元素塔。

滑鼠移到塔上就能看狀態，點一下可以固定狀態卡，並設定攻擊目標或出售。

## 🎒 道具

稀有度由低到高共六種，顏色從白色到彩色：普通 → 優良 → 稀有 → 史詩 → 傳說 → 神話。

| 分類 | 道具 |
|---|---|
| 戰鬥 | 炸彈、修復包、冰凍卷軸、隕石卷軸、雷霆卷軸、地震卷軸、聖盾、末日審判 |
| 增益（持續數波） | 鷹眼藥水、狂暴藥水、急速藥水、會心藥水、點金藥水、狂戰士之血、巨神祝福、眾神之力 |
| 賭運 | 幸運符、保險卡、雙倍券、黃金馬蹄（賭輸時有機率重來）、黃金彩券、三倍券 |
| 塔 | 塔券、升星石、神秘禮盒（開出限定塔） |
| 財富 | 金幣袋、刷新券、寶石袋、寶藏箱 |

打怪時敵人會掉落道具袋，用滑鼠掃過就能撿。精英怪和首領一定會掉。

在戰場的「🎒 道具背包」點一下道具，不會馬上用掉，而是先跳出確認視窗：
- 按「✔ 確定使用」才會用掉。
- 按「✖ 取消」、點視窗外面，或按 ESC，都會取消，道具不會減少。
- 確認視窗打開時遊戲會暫停，戰鬥中也可以慢慢看說明再決定。

## 操作

| 按鍵 | 說明 |
|---|---|
| Q / W / E | 切換到賭場／商店／戰場 |
| 空白鍵 | 賭場：開始或轉動；戰場：開始下一波 |
| ← ↓ →（或 A S D） | SLOT 模式下停止左、中、右輪 |
| N / Enter | 開始下一波 |
| 1 / 2 / 3 | 戰鬥速度 |
| ESC | 暫停 |

## 其他內容

43 種遺物、12 種敵人（含 3 種首領）、天賦樹、圖鑑、3 張地圖。
首領波結束後會轉命運轉盤，每 5 波會開一次寶箱。

音樂共七首不同風格，會依你所在的位置自動切換：主選單、商店、賭場、備戰、戰鬥、首領戰、大抽獎。

## 檔案結構

```
index.html      入口
js/util.js      共用工具
js/data.js      遊戲資料（塔、敵人、遺物、地圖、天賦）← 想調整數值改這裡
js/items.js     道具、Buff、賭運加成、掉落
js/casino.js    賭場與七種遊戲
js/shop.js      商店、強化工坊、升星畫面
js/game.js      戰場（塔防）邏輯
js/art.js       程序化美術（塔、敵人、地圖、符號）
js/audio.js     音效與七首背景音樂
js/fx.js        粒子特效
js/ui.js        介面、各畫面、彈出視窗
js/main.js      主迴圈、輸入、存檔
```

想調整難度，可以改 `js/game.js` 開頭的 `HP_GLOBAL`（敵人血量倍率）和 `GOLD_KILL`（擊殺金幣倍率）。

存檔使用瀏覽器的 localStorage（天賦、圖鑑、最佳紀錄）。
